# 语法风格

## 中文与符号双写

凡语言以中文关键字为主。常见的运算和赋值同时支持**符号**与**中文描述**两种写法，二者完全等价：

```凡
变量 甲 = 3
变量 乙 = 4

打印(甲 + 乙)
打印(甲 加 乙)
```

常见双写：

| 符号 | 中文 | 符号 | 中文 |
| --- | --- | --- | --- |
| `=` | `为` | `+` | `加` |
| `-` | `减` | `*` | `乘` |
| `/` | `除` | `%` | `取余` |
| `==` | `等于` | `!=` | `不等于` |
| `&&` | `且` | `\|\|` | `或` |
| `!` | `非` | `<` | `小于` |
| `<=` | `小于等于` | `>` | `大于` |
| `>=` | `大于等于` | | |

关键字不能用作变量名、函数名或参数名（例如 `加`、`数组`、`模型`）。

## 语句以换行结束

每条语句占一行，以换行结束，**不支持** 用 `;` 在一行内写多条语句。

```凡
变量 x = 1
变量 y = 2
打印(x 加 y)
```

## 括号内可以折行

在 `(`、`[`、`{` 没有闭合之前，可以跨行书写，换行不会被当作语句结束：

```凡
变量 名单 = [
    1,
    2,
    3,
]

变量 分数 = {
    "张三": 90,
    "李四": 85,
}
```

集合字面量允许使用尾随逗号。

## 括号可选

调用函数、书写条件时括号通常可以省略：

```凡
打印 "你好"

如果 真 那么
    打印("成立")
结束
```

仅在可能产生歧义时才需要括号。

## 可读性协助词

`通过` 和 `从` 不做任何运算或翻译，只是帮助代码读起来更像中文句子：

```凡
变量 用户数 = 从 长度(用户列表)
通过 打印("开始处理")

变量 首项 = 从 用户列表[0]
```

它们可以出现在任何表达式前面，解析时会被直接忽略：

```凡
变量 x = 从 通过 计算()
```

注意：它们是上下文相关的软关键字，仅在独立成词且后面紧跟表达式时生效，因此仍可作为标识符的一部分（如 `从年月日`），也可以定义名为 `通过` 的变量。

## 注释

单行注释有两种写法：

```凡
# 这是注释

注释 这也是注释
```

`#` 之后到行尾的内容都会被忽略。`注释` 关键字后需接空白、冒号或行尾。

## 成员访问

`.` 和 `的` 等价，都可用于访问字段、方法和成员：

```凡
变量 s = "abc"

打印(名单[0])
打印(r.宽)
打印(r 的 面积())
打印(分数 的 长度)
```
