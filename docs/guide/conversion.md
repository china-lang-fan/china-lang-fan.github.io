# 类型转换

基础 SDK 的 `转换.凡` 提供数字、字符串、布尔之间的转换。

```凡
导入 "转换" 作为 转换模块

打印(转换模块.转字符串(42))       # 42
打印(转换模块.转整数("12"))        # 12
打印(转换模块.转小数(3))         # 3
打印(转换模块.转布尔("真"))        # 真
```

## 直接转换

| 函数 | 说明 |
| --- | --- |
| `转字符串(值)` | 转字符串；布尔输出 `真`、`假` |
| `转整数(值)` | 小数向零取整；布尔转为 `1`、`0` |
| `转小数(值)` | 转小数 |
| `转布尔(值)` | 按语言真值规则转换 |

## 解析字符串

解析函数返回 `值, 错误`，格式不合法时错误不为空。

| 函数 | 说明 |
| --- | --- |
| `解析整数(文本)` | 解析整数 |
| `解析小数(文本)` | 解析小数 |
| `解析布尔(文本)` | 解析 `真/假`、`true/false`、`1/0`、`yes/no`、`on/off` |

```凡
变量 数字, 错误值 = 转换模块.解析整数("abc")
如果 错误值 != 空 那么
    打印("解析失败")
结束
```
