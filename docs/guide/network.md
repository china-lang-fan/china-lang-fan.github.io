# 网络

基础 SDK 的 `网络.凡` 提供 HTTP 请求、JSON 请求和文件下载能力。

```凡
导入 "网络" 作为 网络模块

变量 结果, 错误值 = 网络模块.获取("https://example.com")
```

## 基本请求

| 函数 | 说明 |
| --- | --- |
| `请求(方法, 地址, 选项)` | 发送 HTTP 请求 |
| `获取(地址, 选项)` | GET 请求 |
| `提交(地址, 选项)` | POST 请求 |
| `更新(地址, 选项)` | PUT 请求 |
| `修补(地址, 选项)` | PATCH 请求 |
| `删除(地址, 选项)` | DELETE 请求 |

请求成功返回 `结果, 空`；网络或 URL 错误返回 `结果, 错误`。

## 请求选项

```凡
变量 结果, 错误值 = 网络模块.提交(地址, {
    "headers": {
        "Content-Type": "text/plain"
    },
    "body": "请求内容",
    "timeout": 10
})
```

| 选项 | 说明 |
| --- | --- |
| `headers` | 请求头字典 |
| `body` | 请求体文本 |
| `timeout` | 超时秒数，默认 30 |

## 响应结构

响应字典包含：

| 字段 | 说明 |
| --- | --- |
| `statusCode` | HTTP 状态码 |
| `statusText` | 状态文本 |
| `body` | 响应体文本 |
| `headers` | 响应头字典，键为小写 |
| `success` | 状态码是否为 2xx |

HTTP 服务端返回 4xx 或 5xx 时，请求本身不会返回错误；可以通过 `success` 或 `statusCode` 判断。

## JSON

| 函数 | 说明 |
| --- | --- |
| `获取JSON(地址, 选项)` | GET JSON，并解码响应体 |
| `提交JSON(地址, 值, 选项)` | 将值编码为 JSON，POST 后解码响应体 |

```凡
变量 值, 错误值 = 网络模块.获取JSON(地址)
```

JSON 辅助函数在状态码不是 2xx 时返回错误。

## 下载文件

`下载(地址, 路径, 选项)` 会读取响应体并写入文件。

```凡
变量 错误值 = 网络模块.下载(地址, "本地文件.txt")
```

下载成功返回 `空`，否则返回错误。
