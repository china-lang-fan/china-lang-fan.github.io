# 类型系统

凡语言是动态类型语言：变量的类型由运行时的值决定。同时支持可选的类型标注，标注后会在运行时强制检查。

## 基本类型

| 类型 | 关键字 | 示例值 |
| --- | --- | --- |
| 整数 | `整数` | `0`、`-42` |
| 小数 | `小数` | `3.14`、`-0.5` |
| 字符串 | `字符串` | `"你好"` |
| 布尔 | `布尔` | `真`、`假` |
| 空 | — | `空` |
| 数组 | `数组` | `[1, 2, 3]` |
| 字典 | `字典` | `{"a": 1}` |
| 错误 | `错误` | `错误("消息")` |
| 任意 | `任意` | 不限定类型 |

不写类型时相当于 `任意`。

## 整数与小数

- 整数字面量：`1`、`100`、`-7`
- 小数字面量：`1.5`、`0.0`、`-3.14`
- 整数和小数混合运算时，结果自动提升为小数。

```凡
变量 整数 a = 3
变量 小数 b = 2.5
变量 c = a + b      # 5.5（小数）
```

## 布尔与空

- 布尔只有 `真` 和 `假` 两个值。
- 凡语言**不做** truthy 转换：`如果`、`当`、`且`、`或` 的操作数必须是布尔。
- `空` 表示没有值，常用于表示“暂无错误”或“未设置”。

```凡
变量 数据 = 空
变量 成功 = 真

如果 成功 那么
    打印("成功")
结束
```

## 数组与字典

数组是有序元素列表，字典是键值对集合，详见 [数组](./arrays) 和 [字典](./dicts)。

```凡
变量 数组 名单 = ["张三", "李四"]
变量 字典 年龄 = {"张三": 20, "李四": 22}
```

## 错误

错误是一种值，通常作为函数的最后一个返回值；没有错误时用 `空` 表示。详见 [错误处理](./errors)。

```凡
变量 错误 e = 错误("出错了")
打印(e.消息)
```

## 类型检查发生在运行时

类型标注不是编译期静态检查，而是在赋值、传参、返回时由解释器校验：

- 变量赋初值 / 重新赋值
- 函数调用时绑定参数
- 函数返回时

```凡
函数 加一(n 整数) -> 整数
    返回 n 加 1
结束

打印(加一(10))    # 11
加一("十")        # 错误：参数 n 类型不匹配
```
