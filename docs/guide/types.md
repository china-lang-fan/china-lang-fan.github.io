# 类型系统

凡语言是动态类型语言：变量的类型由运行时的值决定。同时支持可选的类型标注，标注后会在运行时强制检查。

## 基本类型

| 类型 | 关键字 | 示例值 |
| --- | --- | --- |
| 整数 | `整数` | `0`、`-42` |
| 小数 | `小数` | `3.14`、`-0.5` |
| 字符串 | `字符串` | `"你好"` |
| 字符 | `字符` | `'A'`、`'中'`、`‘中’`、`'\n'` |
| 字节 | `字节` | `65`、`255`（0–255） |
| 布尔 | `布尔` | `真`、`假` |
| 空 | — | `空` |
| 数组 | `数组` | `[1, 2, 3]` |
| 字典 | `字典` | `{"a": 1}` |
| 错误 | `错误` | `错误("消息")` |
| 任意 | `任意` | 不限定类型 |

不写类型时相当于 `任意`。

## 字符串插值

字符串中可以用 `$变量名` 或 `${表达式}` 嵌入运行时的值，免去手动拼接和 `转文本`：

```凡
变量 名称 = "凡语言"
变量 版本 = 5
打印("你好 $名称")              # 你好 凡语言
打印("版本 ${版本 加 1}")       # 版本 6
打印("合计：${3 乘 7} 元")      # 合计：21 元
```

规则：

- `$名称`：插入一个变量的值，名称支持中文，如 `"你好 $名称"`。
- `${表达式}`：插入任意表达式的结果，如 `"${数列[0]}"`、`"${d["键"]}"`，内部可嵌套字符串、字典等带花括号的表达式。
- 插值结果按其文本表示嵌入，整数、小数、布尔、数组、字典等均可；`空` 显示为 `空`。
- 需要字面美元符号时写 `\$`，如 `"价格 \$100"`；`$` 后不跟标识符或 `{` 时按普通字符处理（因此正则等场景不受影响）。
- 插值在运行时求值，引用未声明变量会报错。

## 整数与小数

- 整数字面量：`1`、`100`、`-7`
- 小数字面量：`1.5`、`0.0`、`-3.14`
- 整数和小数混合运算时，结果自动提升为小数。

```凡
变量 整数 a = 3
变量 小数 b = 2.5
变量 c = a + b      # 5.5（小数）
```

## 字符与字节

- **字符**：单个 Unicode 字符，用单引号字面量表示，半角（`'A'`）或全角（`‘中’`）引号均可，支持与字符串相同的转义（`\n`、`\t`、`\r`、`\'`、`\\`）。
  - `'A' < 'B'` 按码点比较；`'A' + 1` 得到 `'B'`；字符可与单字符串拼接。
  - `转换.转字符(65)`、`转换.转字符("凡")` 可从整数或单字符串转换。
- **字节**：0–255 的 8 位无符号整数，主要用于二进制数据。
  - 声明为字节时，0–255 的整数会自动收窄为字节，超出范围报错。
  - 字节参与算术运算的结果是整数；`转换.转字节(值)` 做显式转换并返回 `(字节, 错误)`。

```凡
变量 字符 c = '中'
变量 字节 b = 200

变量 下一个, 错误值 = 转换.转字符(65)
```

## 布尔与空

- 布尔只有 `真` 和 `假` 两个值。
- 凡语言**不做** truthy 转换：`如果`、`当`、`且`、`或` 的操作数必须是布尔。
- `空` 表示没有值，常用于表示“暂无错误”或“未设置”。

```凡
变量 数据 = 空
变量 成功 = 真

如果 成功 那么
    打印("成功")
结束
```

## 数组与字典

数组是有序元素列表，字典是键值对集合，详见 [数组](./arrays) 和 [字典](./dicts)。

```凡
变量 数组 名单 = ["张三", "李四"]
变量 字典 年龄 = {"张三": 20, "李四": 22}
```

## 错误

错误是一种值，通常作为函数的最后一个返回值；没有错误时用 `空` 表示。详见 [错误处理](./errors)。

```凡
变量 错误 e = 错误("出错了")
打印(e.消息)
```

## 自定义类型

可以参考 Go 的 `type 状态 int`，为基本类型定义一个有独立身份的命名类型：

```凡
类型 状态 整数

常量 状态 无效 = 状态(0)
常量 状态 有效 = 状态(1)
常量 状态 已删除 = 状态(2)
```

规则：

- 语法是 `类型 新类型名 底层基本类型`，底层类型目前支持整数、小数、字符串、布尔、字节、字符、数组、字典。
- 新类型和底层类型**不能隐式混用**；把底层值赋给新类型变量时，必须显式调用 `状态(1)`，或用 `1 转为 状态`。
- `状态 是 状态` 为真，`状态 是 整数` 也为真；但普通整数 `1 是 状态` 为假。
- 命名值按底层类型参与等值、大小比较与算术；算术结果回到普通底层类型。
- `类型名(状态值)` 返回自定义类型名（`状态`），不是 `integer`。
- 命名类型可以像字符串等原生类型一样，用“定义 状态 的 方法 …”扩展方法，方法的第一个参数接收该值。

```凡
定义 状态 的 方法 文本(自己) -> 字符串
    判断 自己
        为 无效
            返回 "无效"
        为 有效
            返回 "有效"
    结束
    返回 "未知"
结束

函数 保存(s 状态)
    打印(s.文本())
结束
```

这提供了 Go 风格的轻量枚举用法：不需要专门的 enum 语法，用 `类型` + `常量` 表达固定取值集合即可。

## 类型检查发生在运行时

类型标注不是编译期静态检查，而是在赋值、传参、返回时由解释器校验：

- 变量赋初值 / 重新赋值
- 函数调用时绑定参数
- 函数返回时

```凡
函数 加一(n 整数) -> 整数
    返回 n 加 1
结束

打印(加一(10))    # 11
加一("十")        # 错误：参数 n 类型不匹配
```

类型位置除了基本类型和模型名，还可以写[接口](./interfaces)名：传入的值只要拥有接口要求的全部方法即可。
