# 类型系统

凡语言是动态类型语言：变量的类型由运行时的值决定。同时支持可选的类型标注，标注后会在运行时强制检查。

各基本类型的字面量与使用细节见[基本类型](./basic-types)。本页讲在基本类型之上定义自己的类型：命名类型（含命名联合类型）与匿名联合类型。

## 自定义类型

可以参考 Go 的 `type 状态 int`，为基本类型定义一个有独立身份的命名类型：

```凡
定义 类型 状态 = 整数

常量 状态 无效 = 状态(0)
常量 状态 有效 = 状态(1)
常量 状态 已删除 = 状态(2)
```

类型定义语法（两种分隔符等价，旧写法 `类型 状态 整数` 仍兼容）：

```凡
定义 类型 状态 = 整数
类型 状态 整数
```

规则：

- 新类型和底层类型**不能隐式混用**；把底层值赋给新类型变量时，必须显式调用 `状态(1)`，或用 `1 转为 状态`。
- `状态 是 状态` 为真，`状态 是 整数` 也为真；但普通整数 `1 是 状态` 为假。
- 命名值按底层类型参与等值、大小比较与算术；算术结果回到普通底层类型。
- `类型名(状态值)` 返回自定义类型名（`状态`），不是 `integer`。
- 命名类型可以像字符串等原生类型一样，用“定义 状态 的 方法 …”扩展方法，方法的第一个参数接收该值。

底层类型写成联合类型时，即得到**命名联合类型**（Go 风格的类型别名式约束）：

```凡
定义 类型 编号 为 整数 或 字符串

变量 编号 id = 1        # 合法
id = "A001"             # 合法
id = 真                 # 错误：声明为 编号（整数 或 字符串），实际为 布尔

函数 保存(编号 id)
    # …
结束

变量 v, 成功 = "x" 转为 编号   # 显式转换：满足成员时成功
1 是 编号                     # 真
```


- 命名联合类型的值赋给该类型变量时按成员校验，并自动带上类型身份；可用于参数、返回值、模型字段。
- 别名上可以用 `定义 编号 的 方法 …` 扩展方法；别名没有的方法会委托给内部值（模型/接口/原生方法），如 `形状{}` 联合 `矩形 或 字符串` 后仍可调用矩形的方法。
- 含 `空` 的联合（`定义 类型 结果 为 整数 或 空`）表示可空结果，可用 `是 空` 判断。


```凡
定义 状态 的 方法 文本(状态 自己) -> 字符串
    判断 自己
        为 无效
            返回 "无效"
        为 有效
            返回 "有效"
    结束
    返回 "未知"
结束

函数 保存(状态 s)
    打印(s.文本())
结束
```

这提供了 Go 风格的轻量枚举用法：不需要专门的 enum 语法，用 `类型` + `常量` 表达固定取值集合即可。

## 联合类型

类型位置可以用 `或` 或竖线 `|` 把多个类型连接成联合类型，值只要满足其中**任一**类型即可：

```凡
变量 整数 或 字符串 编号 = 1
编号 = "A001"            # 合法
编号 = 真                # 错误：声明为 整数 或 字符串，实际为 布尔

定义 类型 数值 为 整数 或 字符串

函数 接收(数值 x) -> 整数 或 字符串
    返回 x
结束
```

规则：

- 可以连接两个或更多类型：`整数 | 字符串 | 布尔`，基本类型、模型名、接口名都可以作为成员。
- 两种写法等价：`整数 或 字符串` 与 `整数 | 字符串`；`或` 两侧需有分词边界，推荐写成 `|` 或加空格。
- 联合类型**不能直接作参数类型**，须先用 `定义 类型` 起别名（如上面的 `数值`）。
- 联合中含接口成员时，值的类型等于某个成员，或满足某个接口的方法集即可。
- 含 `字节` 成员时，0–255 的整数仍按字节规则收窄。
- 含 `空` 成员（如 `字符串 或 空`）表示显式允许空值；运行时可用 `是` 判断实际类型后再使用：

```凡
函数 查找(字符串 键) -> 字符串 或 空
    # 找不到时返回 空
结束

变量 结果 = 查找("x")
如果 结果 是 字符串 那么
    打印(结果)
结束
```

联合类型还可以用 `定义 类型 编号 为 整数 或 字符串` 定义为有独立名字的命名联合类型，详见[自定义类型](#自定义类型)。

## 类型检查发生在运行时

类型标注不是编译期静态检查，而是在赋值、传参、返回时由解释器校验：

- 变量赋初值 / 重新赋值
- 函数调用时绑定参数
- 函数返回时

```凡
函数 加一(整数 n) -> 整数
    返回 n 加 1
结束

打印(加一(10))    # 11
加一("十")        # 错误：参数 n 类型不匹配
```

类型位置除了基本类型和模型名，还可以写[接口](./interfaces)名：传入的值只要拥有接口要求的全部方法即可。
