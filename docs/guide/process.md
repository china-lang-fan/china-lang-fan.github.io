# 进程

基础 SDK 的 `进程.凡` 提供脚本参数、环境变量、工作目录、进程信息和外部命令执行能力。

```凡
导入 "进程" 作为 进程模块

变量 参数列表 = 进程模块.args()
系统打印(参数列表)
```

## 脚本参数

运行脚本时可以传入参数：

```bash
fan run 脚本.凡 参数一 参数二
```

| 函数 | 说明 |
| --- | --- |
| `args()` | 返回脚本参数数组，不包含脚本路径 |
| `script()` | 当前脚本路径 |

## 环境变量

| 函数 | 说明 |
| --- | --- |
| `env(名称)` | 读取环境变量，不存在时返回空字符串 |
| `setEnv(名称, 值)` | 设置环境变量，返回错误 |

## 工作目录

| 函数 | 说明 |
| --- | --- |
| `workingDir()` | 当前工作目录 |
| `changeDir(路径)` | 切换工作目录，返回错误 |

## 进程信息

| 函数 | 说明 |
| --- | --- |
| `pid()` | 当前进程 ID |
| `parentPid()` | 父进程 ID |

## 执行外部命令

`run(命令, 参数, 选项)` 用于执行外部命令。

```凡
变量 结果, 错误值 = 进程模块.run("go", ["version"])
如果 错误值 == 空 那么
    系统打印(结果["stdout"])
结束
```

选项支持：

| 选项 | 说明 |
| --- | --- |
| `cwd` | 命令工作目录 |
| `input` | 标准输入 |
| `env` | 追加或覆盖环境变量字典 |

结果字典包含：

| 字段 | 说明 |
| --- | --- |
| `stdout` | 标准输出 |
| `stderr` | 标准错误 |
| `exitCode` | 退出码 |
| `success` | 是否以 0 退出 |

命令无法启动时返回 `结果, 错误`；命令启动成功但返回非零退出码时，不返回错误，而是 `success=false`。

## 只获取输出

`output(命令, 参数, 选项)` 的行为与 `run` 类似，但成功时只返回标准输出。

```凡
变量 文本, 错误值 = 进程模块.output("go", ["version"])
```

非零退出码会转换为错误值。
