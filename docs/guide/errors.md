# 错误处理

凡语言区分两类问题：

- **业务错误**：错误是普通值，函数通过多返回值返回 `值, 错误`。
- **运行时崩溃**：使用 `抛出` 展开调用栈，用 `稍后` 中的 `捕获()` 恢复。

## 错误值

用 `错误("消息")` 创建错误，用 `.消息` 读取消息字符串：

```凡
变量 e = 错误("参数不合法")
打印(e)
打印(e.消息)
```

错误也可以作为类型标注：

```凡
变量 错误 e = 空
```

## 返回值、错误

函数返回 `值, 错误`，由调用方显式检查：

```凡
函数 除法(a 整数、b 整数) -> (整数，错误)
    如果 b 等于 0 那么
        返回 0、错误("除数不能为零")
    结束
    返回 a / b、空
结束

变量 商、e = 除法(10, 0)
如果 e 不等于 空 那么
    打印("出错：", e.消息)
否则
    打印("结果：", 商)
结束
```

## 检查：错误传播语法糖

`检查 调用` 等价于手动判断错误并提前返回：

```凡
函数 安全除法(a 整数、b 整数) -> (整数，错误)
    变量 结果 = 检查 除法(a, b)
    返回 结果、空
结束
```

规则：

- 调用成功时，`检查` 去掉最后的错误返回值。
- 调用失败时，当前函数立即返回该错误。
- 使用 `检查` 的函数，最后一个返回类型必须是 `错误`。
- `检查` 只处理普通错误值，不处理 `抛出`。

## 稍后：延迟调用

`稍后` 类似 Go 的 `defer`，用于注册函数退出时执行的调用。多个 `稍后` 按后进先出执行：

```凡
函数 处理()
    稍后 打印("第二")
    稍后 打印("第一")
结束

处理()
```

输出：

```text
第一
第二
```

`稍后` 的参数在注册时立即求值：

```凡
变量 名 = "旧"
稍后 打印(名)
名 = "新"
```

输出 `旧`。

也可以注册无参匿名函数：

```凡
函数 处理文件()
    稍后 函数()
        打印("关闭文件")
    结束
结束
```

即使函数中发生 `抛出`，已经注册的 `稍后` 也会执行。

## 抛出：运行时崩溃

`抛出` 类似 Go 的 `panic`，但可以抛出任意类型的值：

```凡
抛出 "配置缺失"
抛出 404
抛出 {"路径": "/tmp/a", "原因": "权限不足"}
抛出 空
```

通常建议抛出模型实例，携带结构化信息：

```凡
模型 业务异常
    变量 整数 代码
    变量 字符串 消息
结束

函数 必须为管理员(用户 字典)
    如果 用户["角色"] 不等于 "管理员" 那么
        变量 异常 = 业务异常()
        异常.代码 = 403
        异常.消息 = "没有权限"
        抛出 异常
    结束
结束
```

## 捕获：恢复抛出

`捕获()` 只能在 `稍后` 注册的函数中生效，类似 Go 的 `recover()`：

```凡
函数 安全执行()
    稍后 函数()
        变量 异常 = 捕获()
        打印("已恢复：", 异常)
    结束

    抛出 "测试"
结束

安全执行()
```

没有正在展开的抛出时，`捕获()` 返回 `空`：

```凡
函数 普通函数()
    返回 捕获()
结束
```

`捕获()` 只会消费当前正在展开的值。如果不希望恢复，可以重新抛出：

```凡
稍后 函数()
    变量 异常 = 捕获()
    打印("记录日志")
    抛出 异常
结束
```

## 嵌套调用

抛出会逐层展开调用栈，每层函数的 `稍后` 都会执行，直到某一层的 `稍后` 调用 `捕获()`：

```凡
函数 内层()
    抛出 "深层失败"
结束

函数 外层()
    稍后 函数()
        变量 异常 = 捕获()
        打印("外层恢复：", 异常)
    结束
    内层()
结束

外层()
```

未被捕获的抛出会终止脚本并报告抛出值。

## 如何选择

- 用户输入错误、文件不存在、网络失败、解析失败：使用 `(值, 错误)`。
- 简化错误向上返回：使用 `检查`。
- 资源清理：使用 `稍后`。
- 程序状态损坏、不可继续执行：使用 `抛出`。
- 在边界恢复崩溃：在 `稍后` 中使用 `捕获()`。
