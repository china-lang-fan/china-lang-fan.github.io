# 关键字介绍

凡语言的关键字全部是中文词，总量克制（六十余个），并且大多配有等价的符号写法。本页按用途分类介绍；逐条清单见[关键字参考](../reference/keywords)。

## 为什么用中文关键字

- **可读**：`如果 年龄 大于等于 18 那么` 直接读出逻辑，不需要先翻译成英文再理解。
- **可换**：符号与中文等价，`a + b` 与 `a 加 b`、`obj.x` 与 `obj 的 x` 都可以，按场景选更顺的那种。
- **熟悉**：学过其他语言的开发者，按语义而不是按拼写就能猜到关键字的意思。

## 按用途分类

| 类别 | 关键字 | 说明 |
| --- | --- | --- |
| 声明与定义 | `定义`、`变量`、`常量`、`属性` | `属性` 专用于模型体内声明字段 |
| 类型名 | `整数`、`小数`、`字符串`、`字符`、`字节`、`布尔`、`数组`、`字典`、`错误` | `任意` 是预置类型名，不是关键字 |
| 字面量 | `真`、`假`、`空` | 布尔与空值 |
| 赋值 | `为`、`加等于`、`减等于`、`乘等于`、`除等于`、`自增`、`自减` | 等价于 `=`、`+=`、`++` 等 |
| 运算符 | `加`、`减`、`乘`、`除`、`取余` | 算术 |
| | `等于`、`不等于`、`大于`、`小于`、`大于等于`、`小于等于` | 比较 |
| | `且`、`或`、`非` | 逻辑 |
| | `位与`、`位或`、`异或`、`位取反`、`左移`、`右移` | 位运算 |
| | `是`、`转为` | 类型判断与类型转换 |
| 流程控制 | `如果`、`那么`、`否则`、`否则如果`、`结束` | 条件分支 |
| | `判断`、`其他`、`为`、`当`、`则`、`时` | 多分支选择：`为` 匹配值，`当` 匹配条件，`则`/`时` 引导分支体 |
| | `循环`、`当`、`重复`、`直到`、`次`、`遍历`、`中的` | 各种循环 |
| | `跳出`、`继续` | 循环控制 |
| 函数与方法 | `函数`、`返回` | 函数定义与返回 |
| | `本地` | 原生（native）绑定，见[本地绑定](./functions#本地绑定) |
| | `方法`、`自己`、`的` | 方法定义、默认接收者、成员访问 |
| 模型与接口 | `模型`、`接口`、`类型`、`嵌入` | 数据与抽象的定义 |
| 错误处理 | `检查`、`稍后` | 错误传播、延迟调用（崩溃/恢复为内建函数） |
| 模块与可见性 | `导入`、`公开`、`私有`、`通过` | `通过 模块 函数(...)` 用于跨模块调用 |
| 辅助词 | `从`、`注释` | 见下文 |

## 使用规则

**1. 关键字不能作标识符。** 变量名、函数名、参数名、模型名都不能用关键字。

**2. 符号写法与中文写法等价。** 常见对照：

| 中文 | 符号 | 中文 | 符号 |
| --- | --- | --- | --- |
| `加` | `+` | `等于` | `==` |
| `减` | `-` | `不等于` | `!=` |
| `乘` | `*` | `且` | `&&` |
| `除` | `/` | `或` | `\|\|` |
| `的` | `.` | `非` | `!` |

详见[运算](./operators)。

**3. `从` 是软关键字。** 它只用于"从某处取"的自然语序，独立成词且后面紧跟表达式时被忽略，其他情况下仍是普通标识符（例如函数名 `从年月日` 合法）。

**4. `注释` 是上下文敏感词。** `#` 是注释符号（仅半角）；中文 `注释` 后接空白、冒号或行尾时同样开始一条注释，写成 `注释这是` 这类粘连形式则仍是标识符。
