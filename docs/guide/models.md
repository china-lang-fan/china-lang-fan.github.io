# 模型

模型（model）用于组织数据与行为，设计上参考 Go：

- 模型内**只定义字段**。
- 方法在模型**外部定义**，可以随时扩展。
- 通过**嵌入**复用，而不是继承。
- 不需要接口，采用鸭子类型。

`类` 关键字作为 `模型` 的兼容别名。

## 定义模型

```凡
定义 模型 矩形
    变量 整数 宽
    变量 整数 高
结束
```

字段用 `变量 [类型] 名` 声明，未指定类型时为 `任意`。字段默认值为 `空`。

## 在模型外部定义方法

语法：

```text
定义 <模型名> 的 方法 <方法名>(参数列表) [-> 返回类型]
    方法体
结束
```

方法体内用 `自己` 访问当前实例：

```凡
定义 矩形 的 方法 面积() -> 整数
    返回 自己.宽 乘 自己.高
结束

定义 矩形 的 方法 放大(倍数 整数)
    自己.宽 = 自己.宽 乘 倍数
    自己.高 = 自己.高 乘 倍数
结束
```

`定义` 可省略，方法同样支持参数、返回值类型检查和多返回值。括号同时支持半角 `()` 和全角 `（）`。

## 实例化

用 `模型名()` 创建实例：

```凡
变量 r = 矩形()
r.宽 = 3
r.高 = 4
打印(r 的 面积())    # 12
```

### 初始化方法

如果模型定义了名为 `初始化` 的方法，实例化时会自动调用：

```凡
定义 矩形 的 方法 初始化(宽 整数，高 整数)
    自己.宽 = 宽
    自己.高 = 高
结束

变量 r = 矩形(3, 4)
打印(r 的 面积())
```

没有 `初始化` 方法时不能给 `模型名()` 传参。

### 复合字面量（按字段名初始化）

除了调用 `初始化`，还可以用 `模型名{字段: 值, ...}` 直接按字段名创建实例（类似 Go 的复合字面量）：

```凡
定义 模型 矩形
    公开 变量 整数 宽
    公开 变量 整数 高
结束

变量 r = 矩形{宽: 3, 高: 4}
```

规则：

- **不调用 `初始化`**：复合字面量先建零值实例，再按字段名逐个赋值；未列出的字段保持零值（`空`），也可以只填部分字段：`矩形{宽: 3}`。
- 字段名是**裸标识符**并用 `:` 引导；`{"a": 1}` 仍是[字典](./dicts)字面量，二者不会混淆。
- 允许尾随逗号、跨行，也可以嵌套：`人{姓名: "甲", 地址: 地址{城市: "北京"}}`。
- 字段名写错或重复会报错；字段可见性与普通访问一致（跨模块只能填 `公开` 字段，`私有` 字段禁止）。
- 嵌入字段按 Go 规则**整体赋值**，写嵌入模型名，不能直接写被提升的内部字段：

  ```凡
  变量 w = 狗窝{地址: "北京", 动物: 动物{名字: "旺财"}}
  ```

- 跨模块时在模型名前加模块名：`图形.矩形{宽: 3, 高: 4}`。
- 由标签自定义实现的模型不能用复合字面量构造，仍需用 `模型名(...)`。
- `{` 必须紧跟模型名（中间无空白）；写成 `矩形 {…}` 会被当作别的表达式处理。

## 访问字段与方法

`.` 和 `的` 等价：

```凡
打印(r.宽)
打印(r 的 面积())
```

- 不能给实例动态添加未声明的字段。
- 访问不存在的字段或方法会报错。

## 公开与私有

字段和方法可以用 `公开`、`私有` 修饰：

```凡
定义 模型 账户
    公开 变量 字符串 名字
    私有 变量 整数 余额
结束

定义 账户 的 公开 方法 存款(数额 整数)
    自己.余额 = 自己.余额 加 数额
结束

定义 账户 的 私有 方法 内部密语() -> 字符串
    返回 "密-" + 自己.名字
结束
```

- `公开`：模型外可访问。
- 不写修饰：默认仅同一文件内可访问。
- `私有`：只有该模型**自己的方法**能访问。模型外（包括同文件的其他函数）读写私有字段、调用私有方法都会报错。

## 方法可扩展、可覆盖

方法可以在任意位置定义；后定义的同名方法会覆盖先定义的：

```凡
定义 矩形 的 方法 描述()
    返回 "旧"
结束

定义 矩形 的 方法 描述()
    返回 "新"
结束

打印(矩形().描述())    # 新
```

## 嵌入（组合）

在模型内用 `嵌入 模型名` 复用另一个模型的字段与方法：

```凡
定义 模型 人
    变量 字符串 姓名
结束

定义 人 的 方法 问好()
    返回 自己.姓名
结束

定义 模型 学生
    嵌入 人
    变量 整数 学号
结束

变量 s = 学生()
s.姓名 = "小明"
s.学号 = 1
打印(s.问好())    # 小明（嵌入的字段、方法被提升）
```

### 访问被嵌入的对象

被嵌入的部分可以用**嵌入模型名**直接访问，相当于一个具名字段：

```凡
变量 某个人 = s.人      # 取出被嵌入的“人”部分
打印(s.人.问好())      # 也可限定后调用
s.人.姓名 = "小红"
```

### 歧义与消歧

自身字段优先于提升字段。若同层嵌入的多个模型提供了**同名**字段或方法，直接访问会报“有歧义”，必须用嵌入名限定：

```凡
定义 模型 A
    变量 整数 x
结束
定义 模型 B
    变量 整数 x
结束
定义 模型 C
    嵌入 A
    嵌入 B
结束

变量 c = C()
c.x        # 错误：x 在嵌入链中有歧义
c.A.x = 1  # 正确：用嵌入名限定
c.B.x = 2
```

方法调用（`c.同名方法()`）的歧义规则相同，LSP 会在编辑期标红提示。

### 嵌入与可见性

- 被嵌入模型的 `公开` 与默认级（文件内）成员会提升，外层模型可以访问。
- 被嵌入模型的 `私有` 字段/方法**不会**对外层模型开放；即使外层模型嵌入了它，外层自己的方法里写 `自己.私有字段` 也会报错，只能通过被嵌入模型自己的公开方法间接访问。

## 鸭子类型

只要对象拥有需要的方法，就可以传入，不要求它“是”某个模型：

```凡
函数 让它问好(东西)
    返回 东西.问好()
结束
```

如果希望在调用前就检查“有没有这些方法”，可以用[接口](./interfaces)显式声明方法契约，模型无需声明实现即自动满足。
