# 字典

字典是键值对（key-value）集合，用于按键存取数据。

## 字面量

用花括号创建，每一项写作 `键: 值`，项之间用逗号分隔：

```凡
变量 空字典 = {}
变量 分数 = {"张三": 90, "李四": 85}
```

字面量可以跨行，允许尾随逗号：

```凡
变量 配置 = {
    "调试": 真,
    "版本": 2,
}
```

## 键的类型

键支持四种类型：整数、小数、字符串、布尔。其他类型（数组、字典等）不能作为键。

```凡
变量 d = {}
d[1] = "一"
d[真] = "成立"
d["名称"] = "凡"
```

键按**插入顺序**保存；对已存在的键赋值会覆盖旧值，不改变顺序。

## 读取

用 `字典[键]` 读取：

```凡
变量 分数 = {"张三": 90, "李四": 85}

打印(分数["张三"])   # 90
```

读取**不存在的键返回 `空`**，不会报错：

```凡
打印(分数["王五"])   # 空
```

## 写入与覆盖

对键赋值即可新增或覆盖：

```凡
变量 d = {"a": 1}

d["a"] = 10      # 覆盖
d["b"] = 20      # 新增

打印(d)          # {a: 10, b: 20}
```

## 长度

用内建 `长度` 或成员 `长度`：

```凡
变量 d = {"a": 1, "b": 2}

打印(长度(d))     # 2
打印(d 的 长度)   # 2
```

## 键与值

成员 `键` 和 `值` 分别返回所有键、所有值组成的数组：

```凡
变量 分数 = {"张三": 90, "李四": 85}

打印(分数 的 键)   # [张三, 李四]
打印(分数 的 值)   # [90, 85]
```

## 遍历

- 一个变量：遍历值。
- 两个变量 `遍历 d 中的 键 值`：依次得到键和值。

```凡
变量 d = {"a": 1, "b": 2}

遍历 d 中的 值
    打印(值)
结束

遍历 d 中的 键 值
    打印(键, "->", 值)
结束
```

## 字典 SDK

基础 SDK 中的 `字典.凡` 提供常用字典操作。

```凡
导入 "字典" 作为 字典模块

变量 配置 = {"a": 1}
打印(字典模块.取值或默认(配置, "b", 0))       # 0
打印(字典模块.合并(配置, {"c": 3}))      # {a: 1, c: 3}
```

| 函数 | 说明 |
| --- | --- |
| `键列表(字典)` | 所有键 |
| `值列表(字典)` | 所有值 |
| `条目(字典)` | `[键, 值]` 配对数组 |
| `从条目构建(配对数组)` | 由配对数组创建字典 |
| `克隆(字典)` | 浅拷贝 |
| `合并(字典, 字典...)` | 合并，后者覆盖前者 |
| `包含键(字典, 键)` | 是否包含键 |
| `取值(字典, 键)` | 按键取值 |
| `取值或默认(字典, 键, 默认值)` | 键不存在时返回默认值 |
| `映射值(字典, 函数)` | 变换每个值，函数签名 `(值, 键)` |
| `映射键(字典, 函数)` | 变换每个键 |
| `过滤(字典, 函数)` | 按 `(值, 键)` 过滤 |
| `反转键值(字典)` | 键值互换 |
| `选择(字典, 键数组)` | 只保留指定键 |
| `排除(字典, 键数组)` | 删除指定键 |
| `按值计数(数组, 函数)` | 按函数返回值统计次数 |

## 比较

用 `等于` / `不等于` 做深度比较：键集合相同，且每个键对应的值都相等才为真。

```凡
打印({"a": 1} 等于 {"a": 1})     # 真
打印({"a": 1} 等于 {"a": 2})     # 假
```
