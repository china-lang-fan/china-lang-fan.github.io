# 变量与常量

## 声明变量

变量使用 `变量` 声明，必须赋初值，使用 `=` 或中文 `为`：

```凡
变量 名字 = "小明"
变量 年龄 为 18
```

`定义` 关键字可以加在前面：

```凡
定义 变量 城市 = "北京"
```

## 声明常量

常量使用 `常量`，赋值后不能再次修改：

```凡
常量 圆周率 = 3.14
常量 问候语 = "你好"
```

对常量再次赋值会报错。

## 带类型的声明

可以在变量名前加类型，运行时会检查初始值是否匹配：

```凡
变量 整数 数量 = 10
变量 字符串 标题 = "欢迎"
变量 布尔 开启 = 真
变量 数组 名单 = [1, 2, 3]
变量 字典 配置 = {"调试": 真}
```

类型不匹配会报错：

```凡
变量 整数 x = "abc"   # 错误：声明为 整数，实际为 字符串
```

## 省略关键字的写法

在不引起歧义时，可以直接用 `名字 = 值` 的方式。若变量已存在则是赋值，若不存在则是新声明：

```凡
计数 = 0
计数 = 计数 加 1
```

## 重新赋值

已经声明的变量可以用 `=` 重新赋值。声明了类型的变量，新值也必须是同一类型：

```凡
变量 整数 n = 1
n = 2

变量 字符串 名 = "甲"
名 = "乙"
名 = 3        # 错误：类型不匹配
```

## 多变量声明与赋值

一行可以同时声明多个变量，左侧名字和右侧值用逗号（或顿号）分隔，数量必须一致：

```凡
变量 a, b = 1, 2
变量 c、d = 3、"四"

函数 取两个() -> (整数, 字符串)
    返回 5, "六"
结束
变量 e, f = 取两个()    # 接收多返回值
```

对**已经声明**的变量做多目标赋值时不需要 `变量`：

```凡
变量 x = 0
变量 y = ""
x, y = 7, "八"
```

## 重复声明与未声明

- 同一作用域内重复声明同名变量会报错。
- 使用未声明的变量会报错。
- 在 `如果`、循环等代码块中声明的变量，作用域仅限该块。

```凡
如果 真 那么
    变量 内部 = 1
结束
打印(内部)   # 错误：变量 内部 未声明
```

## 空值

`空` 表示没有值。未标注类型的变量可以赋值为 `空`：

```凡
变量 数据 = 空
数据 = "稍后填入"
```

了解凡语言支持的全部类型，见 [类型系统](./types)。
