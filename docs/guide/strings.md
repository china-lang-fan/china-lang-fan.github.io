# 字符串

字符串的关键字是 `字符串`，字面量用双引号包裹。凡语言的字符串是**不可变值**：所有"修改"操作都返回新字符串，原值不变。

## 字面量

```凡
变量 问候 = "你好"
变量 空串 = ""
变量 引号 = "他说：\"你好\""
```

常用转义：

| 转义 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 制表符 |
| `\r` | 回车 |
| `\"` | 双引号 |
| `\\` | 反斜杠 |
| `\$` | 字面美元符号（关闭插值） |

字符用单引号（`'A'`、`'中'`、`'\n'`），详见[基本类型 · 字符与字节](./basic-types#字符与字节)。

## 字符串插值

用 `$变量名` 或 `${表达式}` 把运行时的值嵌入字符串，免去手动拼接和 `转文本`：

```凡
变量 名称 = "凡语言"
变量 版本 = 5
打印("你好 $名称")              # 你好 凡语言
打印("版本 ${版本 加 1}")       # 版本 6
打印("合计：${3 乘 7} 元")      # 合计：21 元
```

规则：

- `$名称`：插入一个变量的值，名称支持中文。
- `${表达式}`：插入任意表达式的结果，如 `"${数列[0]}"`、`"${d["键"]}"`，内部可嵌套字符串、字典等带花括号的表达式。
- 插值结果按其文本表示嵌入，整数、小数、布尔、数组、字典等均可；`空` 显示为 `空`。
- 需要字面美元符号时写 `\$`；`$` 后不跟标识符或 `{` 时按普通字符处理（因此正则等场景不受影响）。
- 插值在运行时求值，引用未声明变量会报错。

## 拼接与比较

```凡
变量 全名 = "张" + "三"
变量 同  = "abc" 等于 "abc"     # 真
变量 异  = "abc" 不等于 "abd"   # 真
```

- 拼接用 `+` 或 `加`，两侧必须都是字符串；与字符相加会得到字符串。
- `等于` / `不等于`（`==` / `!=`）按**内容**比较，比较的是文本而不是引用。
- 大小比较（`小于`、`大于` 等）按字典序。

## 常用操作

- `长度(文本)` 返回字符数（`长度("你好")` 为 `2`），不是字节数。
- 不可变：`文本.替换(...)` 返回新值，原变量不变，详见[原生类型方法 · 不可变语义](./primitive-methods#不可变语义)。

## 字符串方法

标准库 `字符串.凡` 提供常用文本处理函数，既可以作为模块函数调用，也可以直接作为原生方法挂在字符串上：

```凡
导入 "字符串" 作为 字符串模块

打印(字符串模块.拆分("a,b", ","))   # ["a", "b"]
打印("a,b".拆分(","))               # ["a", "b"]
```

| 函数 | 说明 |
| --- | --- |
| `截取(文本, 开始, 末位置 = -1)` | 按下标截取子串 |
| `位置(文本, 子串)` | 子串首次出现的下标，找不到为 `-1` |
| `包含(文本, 子串)` | 是否包含子串 |
| `开头是(文本, 前缀)` / `结尾是(文本, 后缀)` | 前缀 / 后缀判断 |
| `拆分(文本, 分隔符)` | 拆成数组，空分隔符按字符拆 |
| `连接(列表, 分隔符)` | 数组拼成字符串 |
| `替换(文本, 旧串, 新串)` | 全部替换 |
| `修剪(文本)` | 去掉首尾空白 |
| `转小写(文本)` / `转大写(文本)` | 大小写转换 |
