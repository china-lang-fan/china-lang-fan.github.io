# 模块

当程序变大时，可以拆分成多个文件。每个 `.凡` 文件就是一个模块，通过 `公开`、`私有` 和 `导入` 组织代码。

## 可见性

凡语言有三个可见性级别：

| 关键字 | 模块级声明 | 模型字段/方法 |
| --- | --- | --- |
| 不写（默认） | 仅当前文件可访问 | 仅同一文件可访问 |
| `公开` | 可被其他模块导入访问 | 任意位置可访问 |
| `私有` | 等同默认，仅当前文件 | 仅当前模型自己的方法可访问 |

## 公开与私有

在定义前加 `公开`，把名字暴露给其他文件：

```凡
公开 变量 版本 = "1.0"

公开 函数 加倍(n 整数) -> 整数
    返回 n 乘 2
结束

公开 模型 点
    公开 变量 整数 x
    公开 变量 整数 y
结束
```

支持的写法：

- `公开 变量/常量 名 = 值`
- `公开 函数 名(…) … 结束`
- `公开 模型 名 … 结束`
- `公开 接口 名 … 结束`
- `公开 类型 名 底层类型`

`定义` 总在最前时，可见性写在它后面也合法：`定义 公开 函数 加倍(n 整数) …` 与 `公开 定义 函数 …` 等价。

没有加 `公开` 的名字只能在本文件内使用；显式写 `私有` 表示同一含义：

```凡
私有 函数 内部辅助()
    返回 "私有"
结束
```

### 模型的私有字段与方法

模型字段和方法同样支持 `公开` / `私有`：

- `公开` 字段：模型外可读写。
- 默认字段：只有同一文件中的代码可访问。
- `私有` 字段：只有该模型**自己的方法**内能通过 `自己.字段` 访问，模型外（包括同文件的其他函数）访问都会报错。

```凡
定义 模型 账户
    公开 变量 字符串 名字
    私有 变量 整数 余额
结束

定义 账户 的 方法 初始化(名字 字符串, 余额 整数)
    自己.名字 = 名字
    自己.余额 = 余额
结束

定义 账户 的 公开 方法 存款(数额 整数)
    自己.余额 = 自己.余额 加 数额
结束

定义 账户 的 私有 方法 内部密语() -> 字符串
    返回 "密-" + 自己.名字
结束
```

## 导入

用 `导入 "路径"` 加载模块。不指定名字时，模块名取路径最后一段（去掉 `.凡` 后缀）：

```凡
导入 "mathlib/运算"

打印(运算.加倍(21))
打印(运算.版本)
```

用 `作为` 指定别名：

```凡
导入 "mathlib/运算" 作为 m

打印(m.加倍(5))
```

只有模块中标记为 `公开` 的成员才能通过 `模块名.成员` 访问：

```凡
变量 p = 运算.点()
p.x = 3
p.y = 4

运算.函数式调用()
打印(m.版本)
```

- 可以调用公开函数：`m.加倍(2)`。
- 可以用公开模型实例化：`运算.点()`。
- 访问非公开成员会报错：`m.内部辅助()` 不可用。

## 通过 模块 访问

除 `模块名.函数(...)` 外，还可以用 `通过 模块名 表达式` 让一个表达式在指定模块的公开作用域中求值，普通函数和[分段函数](./functions#分段函数)都适用：

```凡
导入 "数学工具" 作为 工具

打印(通过 工具 最大值([1, 2, 3]))
打印(通过 工具 求([1, 2, 3])的最大值())
```

- `通过` 后只在该模块的**公开**成员中查找；非公开函数（包括分段函数）不可见。
- 分段函数也可以直接用点号跨模块调用：`工具.求(数列)的最大值()`，要求该分段函数以 `公开 函数 …` 声明。

## 路径解析

- 导入路径相对于**当前运行脚本所在目录**解析。
- 可以省略 `.凡` 后缀，也可以显式写出。
- 目录用 `/` 分隔，例如 `"modules/统计/统计"`。

```凡
导入 "modules/统计/统计"
打印(统计.总和([1, 2, 3]))
```

找不到模块会报「找不到模块：…」。

## 只加载一次

同一个模块在一次运行中只会执行一次，重复导入得到的是同一个模块对象（有缓存）。

如果模块之间相互导入形成环，会检测到并报「循环导入」错误。

## 一个完整例子

模块文件 `问候/问候.凡`：

```凡
公开 变量 语言 = "中文"

公开 函数 打招呼(名字 字符串) -> 字符串
    返回 "你好，" 加 名字
结束
```

主程序：

```凡
导入 "问候/问候" 作为 hi

打印(hi.语言)
打印(hi.打招呼("凡"))
```

输出：

```text
中文
你好，凡
```

也可以查看官方示例 [模块示例](../examples/modules)。
