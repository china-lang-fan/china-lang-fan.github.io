# 接口

接口用一组方法签名描述“能做什么”。凡语言的接口是**隐式实现**的，与 Go 相同：模型不需要声明自己实现了哪个接口，只要它拥有接口要求的全部方法，就自动满足该接口。

## 声明接口

```凡
接口 说话者
    方法 说话() -> 字符串
结束
```

接口块内只写方法签名，没有函数体。参数和返回值类型沿用函数的标注语法：

```凡
接口 仓储
    方法 查询(编号 整数) -> (用户, 错误)
    方法 保存(用户 用户) -> 错误
    方法 删除(编号 整数)
结束
```

## 隐式实现

```凡
定义 模型 狗
    变量 字符串 名
结束

定义 狗 的 方法 初始化(名 字符串)
    自己.名 = 名
结束

定义 狗 的 方法 说话() -> 字符串
    返回 "汪：" + 自己.名
结束

函数 介绍(谁 说话者)
    打印(谁.说话())
结束

介绍(狗("阿黄"))    # 汪：阿黄
```

`狗` 没有写任何“实现”声明，但因为它拥有 `说话() -> 字符串` 方法，所以可以传给要求 `说话者` 的函数。

接口名与模型名一样，可以用于变量、参数、返回值的类型位置：

```凡
变量 说话者 主持 = 狗("旺财")

函数 造一个() -> 说话者
    返回 狗("来福")
结束
```

## 检查时机与错误信息

接口满足检查发生在运行时，覆盖变量声明与赋值、函数参数绑定、返回值校验等所有类型检查点。不满足时会给出明确原因：

```text
类型不匹配：声明为 说话者，实际为 实例（缺少方法 说话）
```

`空` 可以赋给任意接口（表示“当前没有值”）；在 `空` 上调用方法仍会报错。

匹配规则按**方法名 + 参数数量**判断；标注为 `任意`（或省略类型）的参数与任意类型兼容。

## 接口嵌入（组合）

接口可以嵌入其他接口，方法集为自身方法与所有嵌入接口方法的并集：

```凡
接口 读者
    方法 读取(长度 整数) -> 字符串
结束

接口 写者
    方法 写入(内容 字符串)
结束

接口 读写者
    嵌入 读者
    嵌入 写者
    方法 关闭()
结束
```

嵌入了未定义的接口、形成循环嵌入，或同名方法签名（参数数量）冲突时都会报错。

## 原生类型也可以满足接口

通过“定义 类型 的 方法”扩展的原生类型方法同样计入方法集：

```凡
接口 可问候
    方法 问候() -> 字符串
结束

定义 字符串 的 方法 问候() -> 字符串
    返回 "你好，" + 自己
结束

函数 打招呼(谁 可问候)
    打印(谁.问候())
结束

打招呼("凡")    # 你好，凡
```

## 与模型嵌入的关系

模型 `嵌入` 另一个模型后，被嵌入模型的方法会提升到外层。接口检查使用同一套提升规则：

- 外层模型自身的方法优先；
- 同层多个嵌入提供同名方法时产生歧义，该模型不满足要求此方法的接口，错误信息会提示“有歧义”。

## 类型判断与转换

`是` 关键字用于判断一个值是不是某个模型或接口（等价于 Java 的 `instanceof`），优先级与比较运算相同：

```凡
变量 谁 = 狗("阿黄")

打印(谁 是 狗)        # 真
打印(谁 是 说话者)    # 真
打印(谁 是 字符串)    # 假

如果 谁 是 狗 那么
    打印("它是狗")
结束
```

- 判断模型时，模型通过 `嵌入` 得到的类型也算命中（凡语言的嵌入是字段摊平，判断按嵌入链匹配）；
- 判断接口时，按方法集是否满足；
- 也可以判断基本类型：`x 是 整数`、`x 是 字符串`、`x 是 字符` 等；
- `空` 对任何接口的判断为真（空可赋给接口），对模型类型为假。

`转为` 关键字把值转换为目标类型，**总是返回两个值：结果 与 是否成功**，失败不抛错（类似 Go 的 `v, ok := v.(T)`）：

```凡
变量 s、ok = 谁 转为 说话者
如果 ok 那么
    打印(s.说话())
结束

变量 n、ok2 = "42" 转为 整数    # 42, 真
变量 坏、ok3 = "abc" 转为 整数   # 空, 假
```

- 转为模型/接口：成功结果为原值本身，失败结果为 `空`、是否为 `假`；
- 转为基本类型：按值做转换（字符串转整数/小数/布尔、数值互转、整数转字节/字符、任意值转字符串等），无法转换时返回 `空, 假`；
- 需要“转换失败立即中断”时，配合 `检查` 或条件判断使用即可。

## 编辑器支持

语言服务器会收集接口符号：

- 接口名与接口方法支持悬停、跳转与补全；
- 接口类型变量的 `.` 成员补全只列出接口方法；
- 无法静态确定类型时不做报错，避免误伤动态写法。
