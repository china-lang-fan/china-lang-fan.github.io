# 函数

函数是可复用的一段代码。凡语言中函数是一等值，可以赋值、传参、从函数返回。

## 定义函数

用 `函数 名(参数) … 结束`：

```凡
函数 打招呼()
    打印("你好")
结束

打招呼()
```

`定义` 关键字可以加在前面：

```凡
定义 函数 再见()
    打印("再见")
结束
```

## 参数

```凡
函数 打招呼(名字)
    打印("你好，", 名字)
结束

打招呼("小明")
```

多个参数用逗号分隔（也支持中文逗号 `，` 和顿号 `、`）：

```凡
函数 求和(a, b)
    返回 a 加 b
结束

打印(求和(2, 3))
```

## 默认参数

参数可以给默认值。调用时没有传入对应参数，就使用默认值：

```凡
函数 问候(名字, 称呼 = "你好")
    打印(称呼, "，", 名字)
结束

问候("小明")
问候("小明", "早上好")
```

- 默认值在调用时计算。
- 默认参数必须放在普通参数后面。

## 可变参数

最后一个参数前加 `...`，表示可以接收任意多个剩余参数；函数体内该参数是数组：

```凡
函数 求和(开头, 其余 ...)
    变量 合计 = 开头
    遍历 其余 中的 数
        合计 = 合计 加 数
    结束
    返回 合计
结束

打印(求和(1, 2, 3, 4))    # 10
```

可变参数也可以声明元素类型：

```凡
函数 求和(开头 整数, 其余 ...整数)
    ...
结束
```

## 返回值

用 `返回` 把结果返回：

```凡
函数 平方(n)
    返回 n 乘 n
结束

打印(平方(5))    # 25
```

没有 `返回` 时函数返回 `空`。

## 类型标注

参数类型写在参数名后面；返回类型用箭头 `->`（全角 `→` 也可以）：

```凡
函数 求和(a 整数、b 整数) -> 整数
    返回 a 加 b
结束

函数 问候(名字 字符串) -> 字符串
    返回 "你好，" 加 名字
结束
```

括号同时支持半角 `()` 和全角 `（）`。调用时会检查参数数量和类型；返回时检查返回值类型。

## 多返回值

`返回` 多个值（用逗号或顿号分隔）；单个返回类型直接写，多个返回类型放在括号里：

```凡
函数 商余(a 整数、b 整数) -> (整数，整数)
    返回 a / b、a % b
结束
```

### 接收多返回值

用多目标声明 / 赋值，变量数必须与返回值数一致：

```凡
变量 商、余数 = 商余(10, 3)
打印(商)      # 3
打印(余数)    # 1

变量 x = 0
变量 y = 0
x、y = 商余(7, 2)
```

### 自动展开

多返回值作为另一个函数的参数时会自动展开：

```凡
函数 相加(a 整数、b 整数)
    返回 a 加 b
结束

打印(相加(商余(10, 3)))   # 相当于 相加(3, 1) → 4
```

## 无参数调用

函数或方法没有参数时，调用括号可以省略：

```凡
函数 开始()
    打印("开始")
结束

开始()
开始
```

模型方法同样适用：

```凡
变量 面积 = r 的 面积()
变量 简写面积 = r 的 面积
```

字段与无参方法同名时，优先按字段访问。

成员形式的无参方法也可以直接写在其他参数中：

```凡
打印(r 的 面积)
```

裸函数名在参数位置仍是函数值，不会自动调用；需要调用时显式写括号，或使用成员形式。

## 闭包

函数可以引用定义位置外层的变量，形成闭包：

```凡
函数 造计数器()
    变量 n = 0
    函数 计数()
        n = n 加 1
        返回 n
    结束
    返回 计数
结束

变量 c = 造计数器()
打印(c())    # 1
打印(c())    # 2
```

## 递归

函数可以调用自身：

```凡
函数 阶乘(n 整数) -> 整数
    如果 n 小于等于 1 那么
        返回 1
    结束
    返回 n 乘 阶乘(n 减 1)
结束

打印(阶乘(5))    # 120
```

## 匿名函数与一等值

可以不写函数名，直接作为值使用：

```凡
变量 翻倍 = 函数(n 整数) -> 整数
    返回 n 乘 2
结束

打印(翻倍(21))    # 42
```

函数也可作为参数传递：

```凡
函数 执行两次(f)
    f()
    f()
结束

执行两次(打招呼)
```

## 括号可选的调用

调用时括号通常可以省略，参数吃到行尾：

```凡
打印 "你好"
打招呼 "小明"
```

接收者形式：`名单 追加 "张三"` 等价于 `追加(名单, "张三")`。
