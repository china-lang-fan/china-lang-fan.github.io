# 函数

函数是可复用的一段代码。凡语言中函数是一等值，可以赋值、传参、从函数返回。

## 定义函数

用 `函数 名(参数) … 结束`：

```凡
函数 打招呼()
    打印("你好")
结束

打招呼()
```

`定义` 关键字可以加在前面：

```凡
定义 函数 再见()
    打印("再见")
结束
```

## 参数

```凡
函数 打招呼(名字)
    打印("你好，", 名字)
结束

打招呼("小明")
```

多个参数用逗号分隔（也支持中文逗号 `，` 和顿号 `、`）：

```凡
函数 求和(a, b)
    返回 a 加 b
结束

打印(求和(2, 3))
```

## 默认参数

参数可以给默认值。调用时没有传入对应参数，就使用默认值：

```凡
函数 问候(名字, 称呼 = "你好")
    打印(称呼, "，", 名字)
结束

问候("小明")
问候("小明", "早上好")
```

- 默认值在调用时计算。
- 默认参数必须放在普通参数后面。

## 可变参数

最后一个参数前加 `...`，表示可以接收任意多个剩余参数；函数体内该参数是数组：

```凡
函数 求和(开头, 其余 ...)
    变量 合计 = 开头
    遍历 其余 中的 数
        合计 = 合计 加 数
    结束
    返回 合计
结束

打印(求和(1, 2, 3, 4))    # 10
```

可变参数也可以声明元素类型：

```凡
函数 求和(开头 整数, 其余 ...整数)
    ...
结束
```

## 返回值

用 `返回` 把结果返回：

```凡
函数 平方(n)
    返回 n 乘 n
结束

打印(平方(5))    # 25
```

没有 `返回` 时函数返回 `空`。

## 类型标注

参数类型写在参数名后面；返回类型用箭头 `->`（全角 `→` 也可以）：

```凡
函数 求和(a 整数、b 整数) -> 整数
    返回 a 加 b
结束

函数 问候(名字 字符串) -> 字符串
    返回 "你好，" 加 名字
结束
```

括号同时支持半角 `()` 和全角 `（）`。调用时会检查参数数量和类型；返回时检查返回值类型。

## 多返回值

`返回` 多个值（用逗号或顿号分隔）；单个返回类型直接写，多个返回类型放在括号里：

```凡
函数 商余(a 整数、b 整数) -> (整数，整数)
    返回 a / b、a % b
结束
```

### 接收多返回值

用多目标声明 / 赋值，变量数必须与返回值数一致：

```凡
变量 商、余数 = 商余(10, 3)
打印(商)      # 3
打印(余数)    # 1

变量 x = 0
变量 y = 0
x、y = 商余(7, 2)
```

### 自动展开

多返回值作为另一个函数的参数时会自动展开：

```凡
函数 相加(a 整数、b 整数)
    返回 a 加 b
结束

打印(相加(商余(10, 3)))   # 相当于 相加(3, 1) → 4
```

## 分段函数

函数名可以分成多段，参数写在各段之间，形成更接近自然语言的调用形式。

```凡
函数 修改用户(当前用户 用户)的状态为(新状态 状态) -> 字符串
    返回 当前用户.名 + ":" + 新状态.值
结束

修改用户(张三)的状态为(无效)
```

分段函数会生成类似 Java 的方法签名：

```text
修改用户(用户)的状态为(状态)
```

返回类型不参与签名。调用时根据实参的运行时类型匹配签名。

### 空末段与省略括号

除最后一段外，每段至少要有一个参数；最后一段可以没有参数，此时末段的 `()` 也可以完全省略：

```凡
函数 修改(用户 用户)的状态为无效()
    用户.状态 = "无效"
结束

函数 修改(用户 用户)的状态为有效
    用户.状态 = "有效"
结束

修改(张三)的状态为无效
修改(张三)的状态为无效()
修改(张三)的状态为有效
```

空末段不消耗实参，签名中仍保留空括号：

```text
修改(用户)的状态为无效()
```

普通零参函数在定义时同样可以省略括号：

```凡
函数 打招呼
    打印("你好")
结束
```

### 段间空白

多段函数调用的各段必须**紧邻**，段与段之间不能有空格：

```凡
从("北京")到("上海")乘坐("高铁")
```

一旦段间出现空格，语言不再把整行视为一次分段函数调用，而是先执行开头的普通调用，再对其返回值做后续成员访问：

```凡
从("北京") 到("上海")
```

上例会先调用普通函数 `从("北京")`，再访问其返回值的 `到` 成员。紧邻时则优先匹配同名分段函数；没有匹配的分段函数时，才按普通函数或成员访问处理。

编辑器（语言服务器）会在段间出现空格时给出黄色告警 `mixfix-space`，提醒这是两件不同的事。详见[编辑器与语言服务器](./editor)。

### 多段与重载

可以定义三段或更多段，也可以基于参数类型重载：

```凡
函数 从(起点 字符串)到(终点 字符串)乘坐(工具 字符串) -> 字符串
    返回 起点 + "->" + 终点 + ":" + 工具
结束

函数 修改(值 字符串)的状态为(状态 字符串) -> 字符串
    返回 "字符串"
结束

函数 修改(值 整数)的状态为(状态 字符串) -> 字符串
    返回 "整数"
结束
```

当前限制：

- 仅普通函数支持。
- 除末段外，每段至少有一个参数。
- 参数必须显式声明类型。
- 不支持默认参数和可变参数。
- 不做隐式类型转换。
- 首段名不能与其他变量重名。

### 跨模块调用

分段函数默认是文件私有的；用 `公开 函数` 声明后，其他文件可以用模块名限定调用：

```凡
# 数学工具.凡
公开 函数 求(数列 数组)的最大值() -> 整数
    ...
结束
```

```凡
导入 "数学工具" 作为 工具

工具.求([1, 2, 3])的最大值()        # 模块名限定
通过 工具 求([1, 2, 3])的最大值()   # 通过 作用域写法
```

非 `公开` 的分段函数不能跨模块调用，会报「找不到匹配的分段函数」。

## 无参数调用

函数或方法没有参数时，定义处和调用处的括号都可以省略：

```凡
函数 开始
    打印("开始")
结束

开始()
开始
```

模型方法同样适用：

```凡
变量 面积 = r 的 面积()
变量 简写面积 = r 的 面积
```

字段与无参方法同名时，优先按字段访问。

成员形式的无参方法也可以直接写在其他参数中：

```凡
打印(r 的 面积)
```

裸函数名在参数位置仍是函数值，不会自动调用；需要调用时显式写括号，或使用成员形式。

## 闭包

函数可以引用定义位置外层的变量，形成闭包：

```凡
函数 造计数器()
    变量 n = 0
    函数 计数()
        n = n 加 1
        返回 n
    结束
    返回 计数
结束

变量 c = 造计数器()
打印(c())    # 1
打印(c())    # 2
```

## 递归

函数可以调用自身：

```凡
函数 阶乘(n 整数) -> 整数
    如果 n 小于等于 1 那么
        返回 1
    结束
    返回 n 乘 阶乘(n 减 1)
结束

打印(阶乘(5))    # 120
```

## 匿名函数与一等值

可以不写函数名，直接作为值使用：

```凡
变量 翻倍 = 函数(n 整数) -> 整数
    返回 n 乘 2
结束

打印(翻倍(21))    # 42
```

函数也可作为参数传递：

```凡
函数 执行两次(f)
    f()
    f()
结束

执行两次(打招呼)
```

## 括号可选的调用

调用时括号通常可以省略，参数吃到行尾：

```凡
打印 "你好"
打招呼 "小明"
```

接收者形式：`名单 追加 "张三"` 等价于 `追加(名单, "张三")`。
