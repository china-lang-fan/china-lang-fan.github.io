# 判断

`判断` 用于多分支选择：拿一个值去匹配多个分支，或按多个条件依次筛选。它比一长串 `否则如果` 更清晰，命中一个分支后立即结束，**不会向下贯穿**。

## 值匹配

```凡
变量 状态码 = 200

判断 状态码
    为 200
        打印("成功")
    为 301、302
        打印("重定向")
    其他
        打印("其他情况")
结束
```

一个 `为` 分支可以列多个候选值，用顿号分隔。

## 条件匹配

`判断` 后不跟值时，分支用 `当` 写条件，从上到下依次判断，第一个为真的分支执行：

```凡
变量 分数 = 85

判断
    当 分数 >= 90
        打印("优秀")
    当 分数 >= 60
        打印("及格")
    其他
        打印("不及格")
结束
```

## 混用

值匹配和条件匹配可以出现在同一个 `判断` 里，按书写顺序依次尝试：

```凡
变量 状态码 = 500

判断 状态码
    为 200
        打印("成功")
    当 状态码 >= 500
        打印("服务器错误")
    其他
        打印("其他情况")
结束
```

## 规则

- **命中即结束**：执行完命中的分支后直接跳到 `结束` 之后，不存在 C 语言那样的贯穿（fall-through），因此也不需要 `跳出`。
- **`其他` 可选**：没有分支命中且没有 `其他` 时，什么都不做；`其他` 建议写在最后。
- **顺序有意义**：条件分支自上而下判断，把更具体的条件写在前面。
- **`判断` 不带值时只能用 `当`**：没有匹配对象，`为` 分支无意义。
- **分支体可以为空**：命中后不做事也是合法的。

## 什么时候用判断，什么时候用如果

| 场景 | 推荐 |
| --- | --- |
| 一个值对多个固定候选（状态码、命令名、枚举） | `判断` + `为` |
| 多个区间或复合条件（分数段、权限组合） | `判断` + `当` |
| 只有一两个分支 | `如果` / `否则` |
| 需要提前返回的连续守卫判断 | 连续的 `如果` 加 `返回` |

## 完整示例

```凡
函数 描述状态(整数 状态码) -> 字符串
    判断 状态码
        为 200
            返回 "成功"
        为 301、302、307
            返回 "重定向"
        为 404
            返回 "未找到"
        其他
            返回 "未知状态"
    结束
结束

打印(描述状态(200))
打印(描述状态(404))
打印(描述状态(418))
```

输出：

```text
成功
未找到
未知状态
```
