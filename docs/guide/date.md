# 日期

基础 SDK 的 `日期.凡` 专注日历日期，不包含时分秒。

```凡
导入 "日期" 作为 日期模块

变量 时间戳, 错误值 = 日期模块.fromYMD(2020, 6, 15)
打印(日期模块.formatDate(时间戳))       # 2020-06-15
```

## 创建、解析和格式化

| 函数 | 说明 |
| --- | --- |
| `fromYMD(年, 月, 日)` | 创建日期，返回 `时间戳, 错误` |
| `parse(文本)` | 解析 `YYYY-MM-DD` |
| `formatDate(时间戳)` | 格式化为 `YYYY-MM-DD` |
| `today()` | 今天零点时间戳 |

## 日期分量

`parts(时间戳)` 返回：

- `year`
- `month`
- `day`
- `weekday`：`0` 表示星期日

也可以直接使用 `weekday(时间戳)`。

## 日历规则

| 函数 | 说明 |
| --- | --- |
| `isLeapYear(年)` | 是否闰年 |
| `daysInMonth(年, 月)` | 当月天数 |

## 日期计算

| 函数 | 说明 |
| --- | --- |
| `addDays(时间戳, 天数)` | 加天数 |
| `differenceInDays(开始, 结束)` | 相差天数 |
| `age(出生日期, 当前日期)` | 按生日是否已到计算周岁 |
