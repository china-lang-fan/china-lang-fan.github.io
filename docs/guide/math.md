# 数学

基础 SDK 的 `数学.凡` 提供常用数学函数和常量。

```凡
导入 "数学" 作为 数学模块

打印(数学模块.平方根(16))       # 4
打印(数学模块.幂(2, 3))      # 8
打印(数学模块.圆周率)             # 3.141592653589793
```

## 常量

- `圆周率`：圆周率
- `自然常数`：自然常数

## 函数

| 函数 | 说明 |
| --- | --- |
| `绝对值(值)` | 绝对值 |
| `向下取整(值)` | 向下取整 |
| `向上取整(值)` | 向上取整 |
| `四舍五入(值)` | 四舍五入 |
| `最小值(数字...)` | 最小值 |
| `最大值(数字...)` | 最大值 |
| `平方根(值)` | 平方根 |
| `幂(底数, 指数)` | 幂 |
| `限制范围(值, 下限, 上限)` | 限制在范围内 |
| `符号(值)` | `-1`、`0` 或 `1` |
| `总和(数组)` | 求和 |
| `平均值(数组)` | 平均值 |
| `斜边长(横向, 纵向)` | 平方和开根 |

`平方根`、`幂` 和 `斜边长` 返回小数；其他函数尽量保留输入的数字类型。
