# 数学

基础 SDK 的 `数学.凡` 提供常用数学函数和常量。

```凡
导入 "数学" 作为 数学模块

打印(数学模块.sqrt(16))       # 4
打印(数学模块.pow(2, 3))      # 8
打印(数学模块.pi)             # 3.141592653589793
```

## 常量

- `pi`：圆周率
- `e`：自然常数

## 函数

| 函数 | 说明 |
| --- | --- |
| `abs(值)` | 绝对值 |
| `floor(值)` | 向下取整 |
| `ceil(值)` | 向上取整 |
| `round(值)` | 四舍五入 |
| `min(数字...)` | 最小值 |
| `max(数字...)` | 最大值 |
| `sqrt(值)` | 平方根 |
| `pow(底数, 指数)` | 幂 |
| `clamp(值, 下限, 上限)` | 限制在范围内 |
| `sign(值)` | `-1`、`0` 或 `1` |
| `sum(数组)` | 求和 |
| `average(数组)` | 平均值 |
| `hypot(横向, 纵向)` | 平方和开根 |

`sqrt`、`pow` 和 `hypot` 返回小数；其他函数尽量保留输入的数字类型。
