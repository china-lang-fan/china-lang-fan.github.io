# 条件控制

## 如果

使用 `如果 … 那么 … 结束`：

```凡
变量 分数 = 85

如果 分数 大于等于 60 那么
    打印("及格")
结束
```

条件必须是布尔值。

## 否则

用 `否则` 处理不成立的情况：

```凡
变量 分数 = 50

如果 分数 大于等于 60 那么
    打印("及格")
否则
    打印("不及格")
结束
```

## 否则如果

用 `否则如果` 串联多个条件：

```凡
变量 分数 = 85

如果 分数 大于等于 90 那么
    打印("优秀")
否则如果 分数 大于等于 80 那么
    打印("良好")
否则如果 分数 大于等于 60 那么
    打印("及格")
否则
    打印("不及格")
结束
```

条件从上到下依次判断，命中第一个为真的分支后结束。

## 块作用域

`如果` 的每个分支都是独立作用域，块内声明的变量外部不可见：

```凡
如果 真 那么
    变量 消息 = "内部"
    打印(消息)
结束

# 打印(消息)  —— 错误：消息未声明
```

## 条件的常见写法

由于不做 truthy 转换，需要显式写出布尔条件：

```凡
变量 名单 = [1, 2, 3]

如果 长度(名单) 大于 0 那么
    打印("名单非空")
结束

变量 数据 = 空
如果 数据 等于 空 那么
    打印("暂无数据")
结束
```

组合条件用 `且` / `或` / `非`：

```凡
变量 年龄 = 25

如果 年龄 大于等于 18 且 年龄 小于 60 那么
    打印("成年人")
结束
```

## 多分支选择

分支较多、或按一个值匹配多个固定候选时，用 [`判断`](./switch) 更清晰：

```凡
判断 状态码
    为 200
        打印("成功")
    为 301、302
        打印("重定向")
    其他
        打印("其他情况")
结束
```

详见 [判断](./switch)。
