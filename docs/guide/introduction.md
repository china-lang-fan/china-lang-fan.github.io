# 介绍

**凡语言：让逻辑回归自然的表达**

凡语言（Fan Language）是一门以自然语言逻辑为导向的通用编程语言。

长久以来，开发者必须去适应计算机的语法习惯。而凡语言的设计核心，是将编程从“符号的拼接”升华为“逻辑的自然陈述”。它允许开发者用最符合直觉的中文语序来构建程序，让代码不仅能够被机器执行，更能被人类顺畅阅读。

在追求表达直白的同时，凡语言拥有扎实的现代语言架构。它采用了组合优于继承的设计哲学，并通过消息发送与鸭子类型让对象协作变得灵活而宽容。其内置的元数据机制，更是将语言语法与底层实现完美解耦，使得凡语言不仅能作为轻量级应用开发的首选，也能从容应对未来的系统级编程与原生编译。

凡语言，用最自然的逻辑，构建最强大的工程。

## 一个例子

```凡
# 模型只定义字段，方法写在模型外部
定义 模型 书
    属性 字符串 书名
    属性 整数 价格
结束

# 嵌入复用：促销书拥有书的全部字段
定义 模型 促销书
    嵌入 书
    属性 小数 折扣
结束

定义 促销书 的 方法 售价() -> 小数
    返回 自己.价格 乘 自己.折扣
结束

# 为字符串扩展方法
定义 字符串 的 方法 加书名号() -> 字符串
    返回 "《" + 自己 + "》"
结束

变量 货品 = 促销书()
货品.书名 = "小王子"
货品.价格 = 30
货品.折扣 = 0.8

打印(货品.书名.加书名号(), "售价", 货品.售价(), "元")
```

运行后输出：

```text
《小王子》售价24元
```

短短十几行，就能看到凡语言的几个核心设计：模型与外部方法、嵌入组合、扩展方法，以及全程的中文表达。

## 设计理念

- **用母语编程**：中文不是翻译层，而是语言的一等公民——关键字、类型、运算都有中文写法，常见运算同时支持符号与中文两种写法，让中文使用者用母语直接思考和表达程序。
- **简单明确**：语法本身保持克制——关键字少而精，语句以换行结束、没有分号；不做隐式类型转换之类的"聪明"魔法，代码行为一眼可辨。
- **组合优于继承**：模型只定义字段，方法在模型外部定义；通过嵌入组合能力，配合消息发送与鸭子类型，对象协作灵活而宽容，避免复杂的继承体系。
- **语法与实现解耦**：内置的标签（元数据）机制，让语言语法与底层实现分离——同一份代码可以由不同运行时承载，从解释执行平滑走向原生编译。
- **错误是值**：函数用 `值, 错误` 多返回值返回错误，用 `检查` 一行传播；`抛出`、`稍后`、`捕获` 只用于致命异常，让错误路径显式可见。
- **渐进的类型**：默认享受动态类型的灵活，需要时为变量、参数加上类型标注，在运行时获得清晰校验——从原型到规范平滑过渡。
