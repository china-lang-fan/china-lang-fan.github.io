# 介绍

凡语言是一门以中文为主要书写方式的通用脚本语言。它的目标是让中文使用者能用自然、可读的方式编写程序，同时借鉴 [Go](https://go.dev/) 的设计哲学，保持语言简单、明确。

## 一个例子

```凡
# 计算矩形面积
定义 模型 矩形
    变量 整数 宽
    变量 整数 高
结束

定义 矩形 的 方法 面积() -> 整数
    返回 自己.宽 乘 自己.高
结束

变量 r = 矩形()
r.宽 = 3
r.高 = 4
打印("面积是：", r 的 面积())
```

运行后输出：

```text
面积是： 12
```

## 设计理念

- **中文优先**：关键字、类型、内置操作都可以用中文；常见运算同时支持符号和中文描述两种写法。
- **简单明确**：语句以换行结束，括号只在必要时使用；没有隐式的类型魔法。
- **组合优于继承**：模型只定义字段，方法在模型外部定义，通过嵌入复用能力，配合鸭子类型。
- **错误是值**：函数通过多返回值返回 `值, 错误`，用 `检查` 传播；致命异常使用 `抛出/稍后/捕获`。

## 主要特性

| 特性 | 说明 |
| --- | --- |
| 变量 / 常量 | 可选类型标注，运行时类型检查 |
| 运算 | 算术、比较、逻辑；字符串拼接 |
| 控制流 | 如果、当、重复、遍历；跳出、继续 |
| 数组 / 字典 | 字面量、下标读写、遍历、深度比较 |
| 函数 | 闭包、递归、多返回值、一等值 |
| 模型 | 字段 + 外部方法、嵌入、鸭子类型 |
| 错误处理 | 错误值、检查、稍后、抛出、捕获 |
| 模块 | 导入、公开/私有、模块缓存 |

## 当前状态

凡语言目前是一个基于树遍历的解释器，使用 Go 实现，包含运行脚本和交互式环境等命令。语言核心已可用于学习、脚本编写和小型项目，仍在持续完善中。
