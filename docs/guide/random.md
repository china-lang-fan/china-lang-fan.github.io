# 随机

基础 SDK 的 `随机.凡` 提供随机数和随机选择功能。

```凡
导入 "随机" 作为 随机模块

打印(随机模块.int(10))
打印(随机模块.choice(["甲", "乙", "丙"]))
```

## 随机数

| 函数 | 说明 |
| --- | --- |
| `int(最大值)` | `[0, 最大值)` 范围内的整数 |
| `intRange(最小值, 最大值)` | `[最小值, 最大值)` 范围内的整数 |
| `float()` | `[0, 1)` 范围内的小数 |
| `floatRange(最小值, 最大值)` | 指定范围内的小数 |
| `bool()` | 随机布尔 |
| `chance(概率)` | 以 `[0, 1]` 的概率返回真 |

## 随机选择

| 函数 | 说明 |
| --- | --- |
| `choice(数组)` | 随机选择一个元素 |
| `shuffle(数组)` | 返回打乱顺序后的新数组 |
| `sample(数组, 数量)` | 随机选取指定数量的元素，不重复 |
| `oneOf(数组)` | `choice` 的别名 |

所有选择函数都不会修改原数组。
