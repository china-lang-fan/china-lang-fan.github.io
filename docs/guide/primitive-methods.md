# 原生类型方法

凡语言允许为原生类型定义方法。当前版本首先支持 `字符串`，整数、小数、布尔、数组和字典将在后续版本逐步支持。

原生类型不会被装箱成普通对象，方法接收者就是原来的值。

## 定义字符串方法

默认接收者名为 `自己`：

```凡
定义 字符串 的 方法 加括号() -> 字符串
    返回 "[" + 自己 + "]"
结束

打印("abc".加括号())    # [abc]
```

也可以显式指定接收者名：

```凡
定义 文本 字符串 的 方法 重复两次() -> 字符串
    返回 文本 + 文本
结束

打印("x".重复两次())    # xx
```

## 带参数的方法

```凡
定义 字符串 的 方法 包围(左 字符串, 右 字符串) -> 字符串
    返回 左 + 自己 + 右
结束

打印("x".包围("(", ")"))    # (x)
```

## 与普通函数的关系

原生方法与普通函数共享同一套函数模型。下面两个定义的核心逻辑等价：

```凡
定义 函数 拆分文本(自己 字符串, 分隔符 字符串) -> 数组
    返回 自己.拆分(分隔符)
结束

定义 字符串 的 方法 拆分(分隔符 字符串) -> 数组
    返回 拆分(自己, 分隔符)
结束
```

方法定义会把接收者作为第一个参数，因此方法模型等价于：

```凡
定义 函数 拆分(自己 字符串, 分隔符 字符串) -> 数组
结束
```

## 扩展与覆盖

同一个类型的同名方法可以重复定义，后定义的方法会覆盖先定义的方法：

```凡
定义 字符串 的 方法 描述() -> 字符串
    返回 "旧"
结束

定义 字符串 的 方法 描述() -> 字符串
    返回 "新"
结束

打印("x".描述())    # 新
```

## 作用范围

原生方法只在当前运行环境内有效：

- 单次脚本运行结束后失效。
- 不同测试文件之间互不污染。
- 不会写入磁盘，也不会跨脚本持久化。
- 导入的模块可以为当前运行注册方法。

## 不可变语义

字符串是不可变值，方法应返回新的字符串，而不是修改原值：

```凡
变量 原文 = "abc"
变量 新文本 = 原文.替换("b", "x")

打印(原文)      # abc
打印(新文本)    # axc
```
