# 原生类型方法

凡语言允许为原生类型（字符串、整数、小数、布尔、数组、字典等）和[命名类型](./types#自定义类型)定义扩展方法。

原生类型不会被装箱成普通对象，方法接收者就是原来的值。命名类型的方法登记在类型自己的名下，查找时优先于底层类型的方法，未命中再回退到底层类型。

## 定义字符串方法

默认接收者名为 `自己`：

```凡
定义 字符串 的 方法 加括号() -> 字符串
    返回 "[" + 自己 + "]"
结束

打印("abc".加括号())    # [abc]
```

也可以显式指定接收者名：

```凡
定义 文本 字符串 的 方法 重复两次() -> 字符串
    返回 文本 + 文本
结束

打印("x".重复两次())    # xx
```

## 带参数的方法

```凡
定义 字符串 的 方法 包围(字符串 左, 字符串 右) -> 字符串
    返回 左 + 自己 + 右
结束

打印("x".包围("(", ")"))    # (x)
```

## 接收者前置写法

调用方法时，接收者可以放在方法名之前，与点号写法等价：

```凡
打印("a,b,c" 拆分(","))    # [a, b, c]
打印("a,b,c".拆分(","))    # 等价写法
```

无参方法也可以省略括号：

```凡
打印("abc" 转大写)    # ABC
打印("abc".转大写())  # 等价写法
```

这种写法也支持普通函数，第一个参数会作为接收者：

```凡
函数 包围(字符串 值, 字符串 记号) -> 字符串
    返回 记号 + 值 + 记号
结束

打印("x" 包围("#"))    # #x#
打印(包围("x", "#"))  # 等价写法
```

## 与普通函数的关系

原生方法与普通函数共享同一套函数模型。下面两个定义的核心逻辑等价：

```凡
定义 函数 拆分文本(字符串 自己, 字符串 分隔符) -> 数组
    返回 自己.拆分(分隔符)
结束

定义 字符串 的 方法 拆分(字符串 分隔符) -> 数组
    返回 拆分(自己, 分隔符)
结束
```

方法定义会把接收者作为第一个参数，因此方法模型等价于：

```凡
定义 函数 拆分(字符串 自己, 字符串 分隔符) -> 数组
结束
```

## 扩展与重复定义

同一个类型可以扩展多个不同名的方法；同名方法重复定义会直接报错，后定义不会覆盖先定义：

```凡
定义 字符串 的 方法 描述() -> 字符串
    返回 "旧"
结束

定义 字符串 的 方法 描述() -> 字符串    # 错误：方法签名重复
    返回 "新"
结束
```

这条规则对普通函数、模型方法、扩展方法、分段函数一致，详见[函数 · 重复定义](./functions#重复定义)。

## 作用范围

扩展方法只能在模块（文件）顶层声明，加载期注册，不能嵌套在函数体内。注册后只在当前运行环境内有效：

- 单次脚本运行结束后失效。
- 不同测试文件之间互不污染。
- 不会写入磁盘，也不会跨脚本持久化。
- 导入的模块可以为当前运行注册方法。

## 不可变语义

字符串是不可变值，方法应返回新的字符串，而不是修改原值：

```凡
变量 原文 = "abc"
变量 新文本 = 原文.替换("b", "x")

打印(原文)      # abc
打印(新文本)    # axc
```
