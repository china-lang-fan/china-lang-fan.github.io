# 继承

凡语言**没有类继承**。它用三种机制覆盖传统继承的用途：

| 传统继承的用途 | 凡语言的替代 |
| --- | --- |
| 复用字段与方法 | 嵌入模型（组合） |
| 多态、按能力调用 | 接口 + 鸭子类型 |
| 给已有类型加能力 | 扩展方法 |

这样做的结果是：类型之间没有继承链，耦合更浅，也不需要处理"父类改动波及所有子类"的问题。

## 为什么不用继承

- **组合优于继承**：把"是什么"（继承）换成"有什么"（嵌入），避免为复用而强行套上不合适的类型关系。
- **模型是纯数据**：模型只声明字段，方法定义在模型外部，天然适合按需组合。
- **多态靠方法集**：只要对象拥有需要的方法就能用，不必事先声明继承关系。

## 嵌入：字段与方法的复用

在模型内用 `嵌入 模型名` 复用另一个模型的字段与方法，被嵌入的成员会**提升**到外层，可以直接访问：

```凡
定义 模型 人
    属性 字符串 姓名
结束

定义 人 的 方法 问好() -> 字符串
    返回 自己.姓名
结束

定义 模型 学生
    嵌入 人
    属性 整数 学号
结束

变量 s = 学生()
s.姓名 = "小明"
s.学号 = 1
打印(s.问好())      # 小明
```

需要访问被嵌入部分本身时，用**嵌入模型名**限定：`s.人.姓名`。多层嵌入时，同名成员需要逐层限定消歧，详见[模型](./models)的「嵌入（组合）」一节。

## 多态：接口与鸭子类型

凡语言的多态不依赖继承，而依赖方法集：

```凡
定义 接口 问好者
    函数 问好() -> 字符串
结束

函数 打招呼(问好者 对方) -> 字符串
    返回 对方.问好()
结束
```

学生、人，甚至自定义了 `问好` 的字符串，都可以直接传入——不需要声明"实现了问好者"。详见[接口](./interfaces)。

## 与继承的对照

| 传统面向对象 | 凡语言 |
| --- | --- |
| `class 子类 extends 父类` | `嵌入 父模型` |
| 父类字段 / 方法 | 提升到外层，可用嵌入名限定访问 |
| 方法重写（override） | 不支持：同一签名重复定义直接报错。需要不同行为时换一个方法名，或在外层方法里转发后加工 |
| 抽象基类 | 接口（显式声明方法契约，模型无需声明即自动满足） |
| 多重继承 | 多个 `嵌入`，同名成员用嵌入名消歧 |
| 给外部类型加方法 | 扩展方法（`定义 类型 的 方法 ...`） |

## 常见迁移方式

- **基类提取公共字段** → 拆成一个小模型，各处 `嵌入` 它。
- **抽象基类 + 子类实现** → 定义接口，用鸭子类型传参。
- **重写改变行为** → 在外层模型定义新名字的方法，内部调用嵌入对象的方法再调整。
- **深继承链** → 平铺成多个小模型 + 接口组合（接口也可以嵌入接口）。
