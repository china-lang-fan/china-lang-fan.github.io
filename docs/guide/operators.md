# 运算

## 算术运算

| 运算 | 符号 | 中文 |
| --- | --- | --- |
| 加 | `+` | `加` |
| 减 | `-` | `减` |
| 乘 | `*` | `乘` |
| 除 | `/` | `除` |
| 取余 | `%` | `取余` |
| 取负 | `-x` | — |

```凡
打印(7 + 3)      # 10
打印(7 减 3)     # 4
打印(2 乘 5)     # 10
```

### 整数除法与提升

- 两端都是整数时，除法结果也是整数，向零截断：

```凡
打印(10 / 3)     # 3
打印(-10 / 3)    # -3
```

- 整数与小数混算，结果自动提升为小数：

```凡
打印(10 / 3.0)   # 3.3333333333333335
```

### 取余

取余只支持整数：

```凡
打印(10 % 3)     # 1
打印(5.5 取余 2) # 错误
```

### 除零

除以或对 `0` 取余会在运行时报错「除数不能为零」。

## 字符串拼接

两个字符串可以用 `+` / `加` 拼接，返回新字符串：

```凡
打印("你好" 加 "，" 加 "凡")   # 你好，凡
```

字符串不会与其他类型隐式转换：

```凡
"数量：" + 3      # 错误：加法不支持 字符串 + 整数
```

数组也可以用 `加` 拼接，详见 [数组](./arrays)。

## 复合赋值

| 符号 | 中文 | 等价 |
| --- | --- | --- |
| `+=` | `加等于` | `x = x 加 y` |
| `-=` | `减等于` | `x = x 减 y` |
| `*=` | `乘等于` | `x = x 乘 y` |
| `/=` | `除等于` | `x = x 除 y` |

```凡
变量 x = 10
x += 5
x 减等于 3
打印(x)    # 12
```

复合赋值也可用于字符串、数组拼接，以及下标和字段。

## 自增与自减

| 符号 | 中文 | 含义 |
| --- | --- | --- |
| `++` | `自增` | 加 `1` |
| `--` | `自减` | 减 `1` |

```凡
变量 i = 1
i++
++i
i--
--i
```

后置形式返回变化前的值，前置形式返回变化后的值。

## 比较运算

| 符号 | 中文 | 含义 |
| --- | --- | --- |
| `==` | `等于` | 相等 |
| `!=` | `不等于` | 不相等 |
| `<` | `小于` | 小于 |
| `<=` | `小于等于` | 小于等于 |
| `>` | `大于` | 大于 |
| `>=` | `大于等于` | 大于等于 |

```凡
打印(3 等于 3)     # 真
打印(2 小于 5)     # 真
打印(1 加 1 等于 2) # 真
```

- 只有同类型才能比较（整数与小数会自动提升后比较）。
- 其他跨类型比较（包括 `等于`）一律报错，不做隐式转换。
- 数组、字典使用 `等于` 做**深度比较**。
- 错误可以与 `空` 比较（用于判断有无错误）。

```凡
[1, 2] 等于 [1, 2]          # 真
{"a": 1} 等于 {"a": 1}      # 真
```

## 位运算

位运算用于整数家族（`整数` 与 `字节`），结果为整数。

| 符号 | 中文 | 含义 |
| --- | --- | --- |
| `&` | `位与` | 按位与 |
| `\|` | `位或` | 按位或 |
| `^` | `异或` | 按位异或 |
| `~` | `位取反` | 按位取反（一元运算） |
| `<<` | `左移` | 左移 |
| `>>` | `右移` | 算术右移 |

```凡
打印(6 位与 3)     # 2
打印(6 位或 1)     # 7
打印(6 异或 3)     # 5
打印(1 左移 4)     # 16
打印(16 右移 2)    # 4
打印(位取反 0)     # -1
```

移位位数不能为负。位运算优先级参考 C/Java：乘法除法高于加减，加减高于移位，移位高于大小比较，比较高于位与/异或/位或，位运算高于等值判断，最后是逻辑与/或。

## 逻辑运算

| 符号 | 中文 | 规则 |
| --- | --- | --- |
| `&&` | `且` | 两侧都为真才为真 |
| `\|\|` | `或` | 任一侧为真即为真 |
| `!` | `非` | 取反 |

操作数必须是布尔，且支持**短路求值**：

```凡
变量 x = 真

打印(x 且 假)       # 假
打印(x 或 假)       # 真
打印(非 x)         # 假
```

短路：`且` 左侧为假时不计算右侧；`或` 左侧为真时不计算右侧。

## 三元表达式

`条件 ? 真值 : 假值`：条件为真返回第二个表达式，否则返回第三个表达式。

```凡
变量 年龄 = 20
变量 结果 = 年龄 大于等于 18 ? "成年" : "未成年"
打印(结果)    # 成年
```

- 条件必须是布尔值。
- 只会计算命中分支，未命中分支不会执行。
- 支持全角符号：`条件 ？ 真值 ： 假值`。

## 优先级与括号

可以用括号明确运算顺序：

```凡
打印(1 + 2 * 3)      # 7
打印((1 + 2) * 3)    # 9
```

一元运算、括号优先于乘除；之后依次是加减、移位、大小比较、位运算（与/异或/或）、等值判断、逻辑与、逻辑或。
