# 运算

凡语言的运算符都有**符号**和**中文关键字**两种写法，二者等价：可以写 `1 + 2`，也可以写 `1 加 2`。

> **关于全角符号**：当前只有**少数**标点支持全角，其余运算符请使用半角符号或中文关键字。各表下方都有标注。推荐直接用中文关键字（`加`、`等于`、`且`），可彻底避开全角/半角问题。

## 算术运算

| 运算 | 符号（半角） | 中文关键字 |
| --- | --- | --- |
| 加 | `+` | `加` |
| 减 | `-` | `减` |
| 乘 | `*` | `乘` |
| 除 | `/` | `除` |
| 取余 | `%` | `取余` |
| 取负 | `-x` | — |

```凡
打印(7 + 3)      # 10
打印(7 减 3)     # 4
打印(2 乘 5)     # 10
```

### 整数除法与提升

- 两端都是整数时，除法结果也是整数，向零截断：

```凡
打印(10 / 3)     # 3
打印(-10 / 3)    # -3
```

- 整数与小数混算，结果自动提升为小数：

```凡
打印(10 / 3.0)   # 3.3333333333333335
```

### 取余与除零

- 取余只支持整数：`打印(10 % 3)` 得 `1`；小数取余报错。
- 除以或对 `0` 取余会在运行时报错「除数不能为零」。

### 字符串与数组拼接

`+` / `加` 还可用于字符串拼接和数组拼接，返回新值：

```凡
打印("你好" 加 "，" 加 "凡")   # 你好，凡
打印([1, 2] 加 [3])           # [1, 2, 3]
```

字符串不会与其他类型隐式转换：`"数量：" + 3` 报错，需先转成字符串。

## 赋值

| 用途 | 符号（半角） | 中文关键字 |
| --- | --- | --- |
| 赋值 | `=` | `为` |
| 加并赋值 | `+=` | `加等于` |
| 减并赋值 | `-=` | `减等于` |
| 乘并赋值 | `*=` | `乘等于` |
| 除并赋值 | `/=` | `除等于` |
| 自增 | `++` | `自增` |
| 自减 | `--` | `自减` |

```凡
变量 x = 10
x += 5
x 减等于 3
变量 i = 1
i++
++i
打印(x)    # 12
```

- `为` 与 `=` 完全等价；复合赋值的四种中文写法与符号等价。
- 后置 `i++` 返回变化前的值，前置 `++i` 返回变化后的值。
- 复合赋值也可用于字符串、数组拼接，以及下标和字段赋值。

## 比较运算

| 含义 | 符号（半角） | 中文关键字 |
| --- | --- | --- |
| 相等 | `==` | `等于` |
| 不等 | `!=` | `不等于` |
| 小于 | `<` | `小于` |
| 小于等于 | `<=` | `小于等于` |
| 大于 | `>` | `大于` |
| 大于等于 | `>=` | `大于等于` |
| 类型判断 | `x 是 类型` | `是` |
| 类型转换 | `x 转为 类型` | `转为` |

```凡
打印(3 等于 3)     # 真
打印(2 小于 5)     # 真
打印(1 加 1 等于 2) # 真
```

- 只有同类型才能比较（整数与小数会自动提升后比较）。
- 其他跨类型比较（包括 `等于`）一律报错，不做隐式转换。
- 数组、字典使用 `等于` 做**深度比较**；错误可以与 `空` 比较以判断有无错误。

```凡
[1, 2] 等于 [1, 2]          # 真
{"a": 1} 等于 {"a": 1}      # 真
```

`是` 与 `转为` 详见[类型系统](./types)。

## 逻辑运算

| 含义 | 符号（半角） | 中文关键字 |
| --- | --- | --- |
| 与 | `&&` | `且` |
| 或 | `\|\|` | `或` |
| 非 | `!` | `非` |

```凡
变量 x = 真
打印(x 且 假)       # 假
打印(x 或 假)       # 真
打印(非 x)         # 假
```

- 操作数必须是布尔，不做 truthy 转换。
- 短路求值：`且` 左侧为假时不计算右侧；`或` 左侧为真时不计算右侧。
- 注意：单个 `|` 是**位或**，不是逻辑或；在类型位置 `整数 | 字符串` 表示[联合类型](./types#联合类型)。

## 位运算

位运算用于整数家族（`整数` 与 `字节`），结果为整数。

| 含义 | 符号（半角） | 中文关键字 |
| --- | --- | --- |
| 按位与 | `&` | `位与` |
| 按位或 | `\|` | `位或` |
| 按位异或 | `^` | `异或` |
| 按位取反（一元） | `~` | `位取反` |
| 左移 | `<<` | `左移` |
| 右移 | `>>` | `右移` |

```凡
打印(6 位与 3)     # 2
打印(6 位或 1)     # 7
打印(6 异或 3)     # 5
打印(1 左移 4)     # 16
打印(16 右移 2)    # 4
打印(位取反 0)     # -1
```

移位位数不能为负。

## 三元表达式

`条件 ? 真值 : 假值`：条件为真返回第二个表达式，否则返回第三个。

```凡
变量 年龄 = 20
变量 结果 = 年龄 大于等于 18 ? "成年" : "未成年"
打印(结果)    # 成年
```

- 条件必须是布尔值；只会计算命中分支。
- **全角支持**：`?` `:` 同时支持全角 `？` `：`，即 `条件 ？ 真值 ： 假值`。

## 优先级

从低到高排列，同一行优先级相同。可用括号 `()` 改变顺序：

| 优先级（低→高） | 符号 | 中文 |
| --- | --- | --- |
| 三元 | `? :` | — |
| 逻辑或 | `\|\|` | `或` |
| 逻辑与 | `&&` | `且` |
| 等值 | `==` `!=` | `等于` `不等于` |
| 按位或 | `\|` | `位或` |
| 按位异或 | `^` | `异或` |
| 按位与 | `&` | `位与` |
| 大小比较 | `<` `<=` `>` `>=` `是` `转为` | `小于` … `大于等于` |
| 移位 | `<<` `>>` | `左移` `右移` |
| 加减 | `+` `-` | `加` `减` |
| 乘除取余 | `*` `/` `%` | `乘` `除` `取余` |
| 一元前缀 | `-` `!` `~` `++` `--` | `非` `位取反` `自增` `自减` |
| 后缀/成员/调用/下标 | `++` `--` `.` `的` `()` `[]` `{}` | — |
| 括号 | `(表达式)` | — |

```凡
打印(1 + 2 * 3)      # 7
打印((1 + 2) * 3)    # 9
打印(真 或 假 且 假)  # 真（且 优先于 或）
```

## 半角与全角支持情况

中文输入法容易打出全角符号。当前支持情况如下（**v0.5 实测**）：

| 全角 | 对应半角 | 是否支持 |
| --- | --- | --- |
| `（）` | `()` | ✅ 支持 |
| `，` | `,` | ✅ 支持（顿号 `、` 也等价于逗号） |
| `：` | `:` | ✅ 支持 |
| `？` | `?` | ✅ 支持 |
| `→` | `->` | ✅ 支持 |
| `‘’` | `''`（字符字面量） | ✅ 支持 |
| `＠` | `@`（标签） | ✅ 支持 |
| `［］` | `[]` | ❌ 不支持 |
| `｛｝` | `{}` | ❌ 不支持 |
| `“”` | `""`（字符串） | ❌ 不支持（字符串只用半角双引号） |
| `＃` | `#`（注释） | ❌ 不支持（注释只用半角 `#`） |
| `．` | `.`（成员/小数点） | ❌ 不支持 |
| `＝` | `=` / `==` | ❌ 不支持 |
| `！` | `!` / `!=` | ❌ 不支持 |
| `＋－＊／％` | `+ - * / %` | ❌ 不支持 |
| `＜＞` | `< > <= >= << >>` | ❌ 不支持 |
| `＆｜＾～` | `& | ^ ~ && ||` | ❌ 不支持 |
| `＋＝` `＋＋` 等 | `+=` `++` | ❌ 不支持 |
| `；` | `;`（语句分隔） | ❌ 不支持（语句以换行结束，本来就不用分号） |

不支持的全角符号会报「非法字符」或语法错误；运算场景请改用半角符号或中文关键字。
