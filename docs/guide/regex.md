# 正则

基础 SDK 的 `正则.凡` 提供正则匹配、查找、捕获分组、替换、拆分和元字符转义。

```凡
导入 "正则" 作为 正则模块

变量 是否匹配, 错误值 = 正则模块.match("\\d+", "abc123")
```

正则语法遵循 Go 的 `regexp` RE2 方言，不支持反向引用。

## 匹配和查找

| 函数 | 说明 |
| --- | --- |
| `match(模式, 文本)` | 是否匹配，返回 `布尔, 错误` |
| `find(模式, 文本)` | 返回第一个匹配文本 |
| `findAll(模式, 文本, 数量=-1)` | 返回所有匹配文本数组 |

没有匹配时：

- `find` 返回空字符串
- `findAll` 返回空数组

## 捕获分组

| 函数 | 说明 |
| --- | --- |
| `groups(模式, 文本)` | 第一次匹配的完整结果和所有分组 |
| `allGroups(模式, 文本, 数量=-1)` | 所有匹配的分组数组 |

```凡
变量 分组结果, 错误值 = 正则模块.groups("([a-z]+)(\\d+)", "abc123")
# ["abc123", "abc", "123"]
```

分组数组的第 1 项是整个匹配，之后依次是捕获组。未参与匹配的可选分组为 `空`；没有匹配时返回空数组。

## 替换和拆分

| 函数 | 说明 |
| --- | --- |
| `replace(模式, 文本, 替换内容, 数量=1)` | 替换指定次数 |
| `replaceAll(模式, 文本, 替换内容)` | 替换全部匹配 |
| `split(模式, 文本, 数量=-1)` | 按正则拆分 |

替换内容支持使用 `$1`、`$2` 引用捕获分组。

## 转义

`escape(文本)` 会转义正则表达式元字符，使文本可以作为字面量模式使用。
