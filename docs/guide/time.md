# 时间

基础 SDK 的 `时间.凡` 提供时间戳、格式化、解析、时间分量和时间计算。

```凡
导入 "时间" 作为 时间模块

打印(时间模块.当前时间戳())
打印(时间模块.格式化当前时间())
```

## 时间戳

| 函数 | 说明 |
| --- | --- |
| `当前时间戳()` | 当前 Unix 秒级时间戳 |
| `当前毫秒时间戳()` | 当前毫秒级时间戳 |

## 格式化与解析

时间格式使用 Go 的参考时间 `2006-01-02 15:04:05`。

| 函数 | 说明 |
| --- | --- |
| `格式化(时间戳, 布局?)` | 格式化时间 |
| `格式化当前时间(布局?)` | 格式化当前时间 |
| `今日日期文本()` | 当前日期 `YYYY-MM-DD` |
| `解析(布局, 文本)` | 返回 `时间戳, 错误` |
| `默认解析(文本)` | 按完整日期时间解析 |
| `解析日期(文本)` | 按日期解析 |

## 时间分量

`时间分量(时间戳)` 返回包含以下键的字典：

`year`、`month`、`day`、`hour`、`minute`、`second`、`weekday`

## 时间计算

| 函数 | 说明 |
| --- | --- |
| `加秒(时间戳, 秒数)` | 加秒 |
| `加分钟(时间戳, 分钟数)` | 加分钟 |
| `加小时(时间戳, 小时数)` | 加小时 |
| `加天数(时间戳, 天数)` | 加天 |

也可以使用 `休眠(秒数)` 暂停当前程序。
