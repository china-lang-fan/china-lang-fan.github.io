# 标签

标签使用 `@模型名` 声明。标签后面必须是一个已定义的模型，解释器会根据模型字段创建真实的标签实例。

标签不是注解。没有注册处理器时，标签仅作为元数据保存在模型、函数或方法上。

## 支持目标

标签可以用于：

- 模型
- 顶层函数
- 模型方法

```凡
模型 标记
    变量 说明
结束

@标记(说明 = "标签示例")
定义 函数 测试()
    返回 42
结束
```

## 标签参数

未命名参数最多一个，并写入标签模型的 `值` 字段：

```凡
@内建("打印")
定义 函数 输出(内容 ...)
    返回 空
结束
```

命名参数写入同名字段：

```凡
@标记(说明 = "测试")
定义 函数 测试()
    返回 空
结束
```

标签实例不会调用模型的 `初始化` 方法，而是直接按字段写入元数据。

## Go 标准接口

解释器在 `internal/tagsys` 中定义标签标准接口：

- `Callable`：统一可调用对象
- `Target`：标签目标
- `Context`：标签处理上下文
- `Handler`：标签处理器

处理器可以通过上下文替换目标的当前实现。目标对象本身不会被替换，参数数量、参数类型和返回类型契约仍然生效。

上下文包含：

- `标签`：当前标签实例
- `目标`：标签目标
- `当前实现`：替换前的实现
- `替换实现(函数)`：替换当前实现

方法实现接收实例作为第一个参数。普通凡语言函数通过 `替换实现` 替换方法时，需要显式声明该参数；Go 内建函数不接收实例参数，解释器会自动忽略方法实例。

## 内建标签

`@内建` 是内建标签。它会读取标签实例的 `值`，从内建函数注册表查找对应实现，并替换函数当前实现。

```凡
@内建("打印")
定义 函数 输出(内容 ...)
    返回 空
结束

输出("你好，", "凡")
```

输出：

```text
你好， 凡
```

`print` 和 `打印` 都指向 Go 中实现的打印函数。找不到指定内建函数时，会在解释阶段报错。

## 方法标签

方法标签替换的是该方法的实现：

```凡
模型 用户
结束

@内建("打印")
定义 用户 的 方法 输出(内容 ...)
    返回 空
结束

用户().输出("你好")
```

`@内建` 调用的是不接收实例参数的 Go 函数，因此解释器会自动忽略绑定方法时的实例。普通凡语言函数替换方法时，第一个参数是实例：

```凡
函数 新方法(实例, 编号 整数)
    返回 编号
结束

函数 处理标签(上下文)
    上下文.替换实现(新方法)
结束
```

## 在凡语言中注册标签实现

使用 `注册标签处理` 可以把凡语言函数注册为标签处理器：

```凡
模型 自定义
    变量 值
结束

函数 新实现()
    返回 "来自凡语言"
结束

函数 处理自定义(上下文)
    上下文.替换实现(新实现)
结束

注册标签处理("自定义", 处理自定义)

@自定义("参数")
定义 函数 测试()
    返回 空
结束

打印(测试())
```

输出：

```text
来自凡语言
```

## 处理顺序

解释标签时：

1. 根据标签名解析模型
2. 求值标签参数
3. 创建标签模型实例
4. 将标签实例附加到目标元数据
5. 查找 Go 处理器
6. Go 处理器不存在时查找凡语言处理器
7. 处理器替换目标当前实现

同一目标有多个标签时，按声明顺序处理；后一个标签的 `当前实现` 是前一个标签替换后的实现。
