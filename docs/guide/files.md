# 文件

基础 SDK 的 `文件.凡` 提供文件和目录操作。所有可能失败的函数都通过 `错误` 返回失败原因。

## 读取与写入

```凡
导入 "文件" 作为 文件模块

变量 写入错误 = 文件模块.write("a.txt", "你好")
如果 写入错误 != 空 那么
    打印(写入错误)
结束

变量 内容, 读取错误 = 文件模块.read("a.txt")
如果 读取错误 == 空 那么
    打印(内容)
结束
```

也可以使用 `append` 追加内容。

## 复制、移动和删除

| 函数 | 说明 |
| --- | --- |
| `copy(源路径, 目标路径)` | 读取源文件并写入目标文件 |
| `move(旧路径, 新路径)` | 移动或重命名 |
| `remove(路径)` | 删除文件或空目录 |
| `removeAll(路径)` | 递归删除目录及其内容 |

## 目录

| 函数 | 说明 |
| --- | --- |
| `makeDir(路径, 递归?)` | 创建目录 |
| `ensureDir(路径)` | 递归创建目录 |
| `list(路径)` | 返回目录项数组；目录名以分隔符结尾 |
| `stat(路径)` | 返回名称、大小、是否目录、权限和修改时间 |
| `exists(路径)` | 是否存在 |
| `isFile(路径)` | 是否为文件 |
| `isDir(路径)` | 是否为目录 |

## 临时文件和目录

```凡
变量 目录, 错误值 = 文件模块.tempDir("fan-")
如果 错误值 == 空 那么
    # 使用目录
    文件模块.removeAll(目录)
结束
```

可使用 `tempFile(前缀?)` 创建临时文件，返回文件路径。

## 路径工具

| 函数 | 说明 |
| --- | --- |
| `join(部分...)` | 使用当前操作系统的分隔符拼接路径 |
| `pathSeparator()` | 当前路径分隔符 |
| `fileName(路径)` | 文件名 |
| `fileExtension(路径)` | 文件扩展名 |
| `parent(路径)` | 父目录 |
