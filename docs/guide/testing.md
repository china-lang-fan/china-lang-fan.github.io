# 测试

凡语言内置轻量测试框架，测试文件使用 `_测试.凡` 或 `_test.凡` 后缀。

## 编写测试

测试函数不能有参数。函数名以 `测试` 或 `Test` 开头时，会被自动识别：

```凡
导入 "字符串" 作为 字符串模块
导入 "测试" 作为 测试模块

函数 测试拆分()
    测试模块.断言相等(字符串模块.split("a,b", ","), ["a", "b"])
结束
```

也可以使用 `@测试` 标签标记测试函数：

```凡
@测试
函数 标签用例()
    测试模块.断言为真(真)
结束
```

## 运行测试

在项目目录执行：

```shell
fan test
```

也可以指定文件或目录：

```shell
fan test sdk
fan test sdk/字符串_测试.凡
```

测试通过时退出码为 `0`；任意测试失败时退出码非零。

## 断言函数

`测试` 模块提供：

- `断言相等(实际, 期望, 消息?)`
- `断言不相等(实际, 不期望, 消息?)`
- `断言为真(值, 消息?)`
- `断言为空(值, 消息?)`

断言失败会立即停止当前测试，并显示失败原因。
