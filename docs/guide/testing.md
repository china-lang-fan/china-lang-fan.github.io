# 测试

凡语言内置轻量测试框架：不需要额外依赖，测试就是普通的 `.凡` 文件，用命令行一次性跑完。

## 测试文件

- 文件名以 `_测试.凡` 或 `_test.凡` 结尾（例如 `字符串_测试.凡`）。
- 与被测模块放在同一目录，命名一一对应是最常见的做法。
- 文件顶层的 `导入`、常量、辅助函数会在执行用例前先求值一遍，可以当作共享的测试准备。

## 编写用例

用例是一个**没有参数**的顶层函数，满足以下任一条件即被识别：

- 函数名以 `测试` 或 `Test` 开头；
- 函数上带 `@测试` 标签。

```凡
导入 "库/字符串" 作为 字符串模块
导入 "库/测试" 作为 测试模块

函数 测试拆分()
    测试模块.断言相等(字符串模块.拆分("a,b", ","), ["a", "b"])
结束

@测试
函数 标签用例()
    测试模块.断言为真(真)
结束
```

普通函数不会被当成用例，可以在同一个文件里放心写辅助函数。

## 断言

`库/测试.凡` 提供四个断言函数：

| 断言 | 说明 |
| --- | --- |
| `断言相等(实际, 期望, 消息?)` | 实际值等于期望值，数组、字典按内容比较 |
| `断言不相等(实际, 不期望, 消息?)` | 两值不相等 |
| `断言为真(值, 消息?)` | 值为 `真` |
| `断言为空(值, 消息?)` | 值为 `空` |

断言失败会立即停止当前用例，并显示失败原因；其余用例继续执行。

## 运行

在项目目录执行：

```shell
fan 测试
```

也可以指定目录或单个文件（目录会递归发现子目录中的测试文件）：

```shell
fan 测试 测试
fan 测试 测试/字符串_测试.凡
```

输出按文件分组，每个用例一行：

```text
测试/字符串_测试.凡
  ✓ 测试拆分
  ✓ 测试标签用例

文件 1 个，通过 2 项，失败 0 项
```

失败时显示用例名、行号与原因（`✗ 测试名（第12行）：原因`），并以非零退出码结束，方便接入 CI。

## 编写建议

- **一个用例只验证一件事**，失败信息才好定位。
- **用断言而不是 `打印`**：打印不会让测试失败。
- **失败用例优先复现**：单独把文件名传给 `测试` 命令，能快速缩小范围。
- **共享逻辑放辅助函数**，不要塞进入口用例。
