# 内建函数

凡语言目前提供以下内建函数，可以直接调用，无需导入。

## 打印

输出一个或多个值到标准输出，多参数以空格连接，并在末尾换行。

```凡
打印("你好")
打印("a：", 1, "b：", 真)
打印 [1, 2, 3]
```

```text
你好
a： 1 b： 真
[1, 2, 3]
```

## 长度

返回集合的长度，支持数组、字符串和字典。

| 参数 | 返回 |
| --- | --- |
| 数组 | 元素个数 |
| 字符串 | 字符（rune）个数 |
| 字典 | 键值对个数 |

```凡
打印(长度([1, 2, 3]))     # 3
打印(长度("你好"))         # 2
打印(长度({"a": 1}))      # 1
```

## 追加

`追加(数组, 值…)`：返回在数组末尾加入一个或多个新元素后的**新数组**，不修改原数组。

```凡
变量 a = [1, 2]

打印(追加(a, 3))         # [1, 2, 3]
打印(追加(a, 3, 4, 5))   # [1, 2, 3, 4, 5]
打印(a)                 # [1, 2]
```

第一个参数必须是数组。

## 错误

`错误("消息")`：创建一个错误值。消息参数会被转为文本。

```凡
变量 e = 错误("出错了")
打印(e)                 # 错误：出错了
打印(e.消息)            # 出错了
```

错误处理的完整用法见 [错误处理](../guide/errors)。

## 注册标签处理

`注册标签处理(标签名, 处理函数)`：把凡语言函数注册为标签处理器。

```凡
注册标签处理("自定义", 处理函数)
```

标签系统的完整说明见 [标签](../guide/tags)。

## 成员形式速查

部分功能也可通过成员访问获得：

| 接收者 | 成员 | 说明 |
| --- | --- | --- |
| 数组 | `长度` | 元素个数 |
| 数组 | `反转` | 反转后的新数组 |
| 字典 | `长度` | 键值对个数 |
| 字典 | `键` | 键组成的数组 |
| 字典 | `值` | 值组成的数组 |
| 错误 | `消息` | 消息字符串 |

```凡
[1, 2, 3] 的 长度
{"a": 1} 的 键
错误("x").消息
```

更多内建函数（数学、类型转换、输入输出等）将在标准库中逐步提供。
