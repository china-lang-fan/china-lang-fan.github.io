# 关键字

下表列出凡语言当前保留的关键字。关键字不能用作变量名、常量名、函数名、参数名、模型名或方法名。

## 声明

| 关键字 | 作用 |
| --- | --- |
| `定义` | 定义变量 / 函数 / 模型的前缀（常可省略） |
| `变量` | 声明变量 |
| `常量` | 声明常量 |

## 类型

| 关键字 | 类型 |
| --- | --- |
| `整数` | 整数 |
| `小数` | 小数 |
| `字符串` | 字符串 |
| `布尔` | 布尔 |
| `数组` | 数组 |
| `字典` | 字典 |
| `错误` | 错误 |

## 字面量

| 关键字 | 值 |
| --- | --- |
| `真` | 布尔真 |
| `假` | 布尔假 |
| `空` | 空值 |

## 流程控制

| 关键字 | 作用 |
| --- | --- |
| `如果` | 条件语句开始 |
| `判断` | 多分支选择开始 |
| `为` | 判断中的值匹配分支 |
| `其他` | 判断中的默认分支 |
| `那么` | 引入条件成立的分支 |
| `否则` | 条件不成立的分支 |
| `否则如果` | 后续条件分支 |
| `结束` | 块结束 |
| `当` | 当循环 |
| `循环` | 循环体标记 |
| `重复` | 重复循环 / 固定次数 |
| `直到` | 重复循环的结束条件 |
| `次` | 固定次数循环 |
| `遍历` | 遍历循环 |
| `中的` | 遍历中引入元素变量 |
| `跳出` | 跳出循环 |
| `继续` | 进入下一次循环 |

## 函数 / 模型

| 关键字 | 作用 |
| --- | --- |
| `函数` | 定义函数 / 方法 |
| `返回` | 返回值（也可用于声明返回类型） |
| `模型` | 定义模型 |
| `类` | `模型` 的兼容别名 |
| `方法` | 定义模型或原生类型方法 |
| `自己` | 默认接收者（模型实例或原生值） |
| `的` | 成员访问（等价于 `.`） |
| `嵌入` | 模型中嵌入另一个模型 |

## 错误处理

| 关键字 | 作用 |
| --- | --- |
| `检查` | 自动传播错误 |
| `尝试` | 尝试块开始 |
| `捕获` | 捕获错误 |

## 模块

| 关键字 | 作用 |
| --- | --- |
| `导入` | 导入模块 |
| `导出` | 导出名字 |

## 注释

`#` 是注释符号；`注释` 关键字也用于书写单行注释。

另见 [内建函数](./builtins)。
