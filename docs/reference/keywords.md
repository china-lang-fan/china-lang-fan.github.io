# 关键字

下表列出凡语言当前保留的关键字。关键字不能用作变量名、常量名、函数名、参数名、模型名或方法名。按用途分类的介绍见[指南 · 关键字介绍](../guide/keywords)。

## 声明与定义

| 关键字 | 作用 |
| --- | --- |
| `定义` | 定义函数 / 模型 / 接口 / 方法 / 类型的前缀（常可省略） |
| `变量` | 声明变量 |
| `常量` | 声明常量 |
| `属性` | 声明模型字段（模型体内专用，可加 `公开` / `私有`） |

## 类型名

| 关键字 | 类型 |
| --- | --- |
| `整数` | 整数 |
| `小数` | 小数 |
| `字符串` | 字符串 |
| `字符` | 单个 Unicode 字符 |
| `字节` | 0–255 的字节 |
| `布尔` | 布尔 |
| `数组` | 数组 |
| `字典` | 字典 |
| `错误` | 错误值 |

`任意` 是预置类型名，不占用关键字。

## 字面量

| 关键字 | 值 |
| --- | --- |
| `真` | 布尔真 |
| `假` | 布尔假 |
| `空` | 空值 |

## 赋值

| 关键字 | 作用 |
| --- | --- |
| `为` | 赋值（`=`），判断语句中同时用作值匹配分支 |
| `加等于` / `减等于` / `乘等于` / `除等于` | 复合赋值（`+=` 等） |
| `自增` / `自减` | `++` / `--` |

## 运算

| 关键字 | 作用 |
| --- | --- |
| `加` / `减` / `乘` / `除` / `取余` | 算术运算 |
| `等于` / `不等于` | 相等性比较 |
| `大于` / `小于` / `大于等于` / `小于等于` | 大小比较 |
| `且` / `或` / `非` | 逻辑运算 |
| `位与` / `位或` / `异或` / `位取反` / `左移` / `右移` | 位运算 |
| `是` | 类型判断，如 `x 是 整数` |
| `转为` | 类型转换，如 `x 转为 字符串` |

## 流程控制

| 关键字 | 作用 |
| --- | --- |
| `如果` | 条件语句开始 |
| `那么` | 引入条件成立的分支 |
| `否则` | 条件不成立的分支 |
| `否则如果` | 后续条件分支 |
| `结束` | 块结束 |
| `判断` | 多分支选择开始 |
| `为` | 判断中的值匹配分支 |
| `当` | `判断` 中的条件匹配分支；`当` 循环开始 |
| `其他` | `判断` 中的默认分支 |
| `则`、`时` | `判断` 分支体引导词，二者等价；可接同一行单条语句或换行多行块 |
| `循环` | 循环体标记 |
| `重复` | 重复循环 / 固定次数 |
| `直到` | 重复循环的结束条件 |
| `次` | 固定次数循环 |
| `遍历` | 遍历循环 |
| `中的` | 遍历中引入元素变量 |
| `跳出` | 跳出循环 |
| `继续` | 进入下一次循环 |

## 函数与方法

| 关键字 | 作用 |
| --- | --- |
| `函数` | 定义函数 / 方法 |
| `本地` | 声明原生（native）绑定，把函数绑定到解释器原生实现，见[本地绑定](../guide/functions#本地绑定) |
| `返回` | 返回值（也可用于声明返回类型） |
| `方法` | 定义模型或原生类型方法 |
| `自己` | 默认接收者（模型实例或原生值） |
| `的` | 成员访问（等价于 `.`） |

## 模型与接口

| 关键字 | 作用 |
| --- | --- |
| `模型` | 定义模型 |
| `接口` | 定义接口 |
| `类型` | 定义命名类型 / 命名联合类型 |
| `嵌入` | 模型中嵌入另一个模型，或接口嵌入接口 |

## 错误处理

| 关键字 | 作用 |
| --- | --- |
| `检查` | 自动传播普通错误值 |
| `稍后` | 注册函数退出时执行的调用，类似 Go `defer` |

> 崩溃与恢复不是语句关键字，而是一对内建函数：`崩溃了(错误描述)` 触发崩溃（类似
> Go `panic`），`恢复()` 在 `稍后` 中取回崩溃错误（类似 Go `recover`）。

## 模块与可见性

| 关键字 | 作用 |
| --- | --- |
| `导入` | 导入模块 |
| `公开` | 声明公开成员，可跨模块访问 |
| `私有` | 声明私有成员（模型私有字段/方法仅限本模型方法访问） |
| `通过` | 跨模块调用前缀，如 `通过 工具 加倍(3)` |

## 软关键字

| 关键字 | 作用 |
| --- | --- |
| `从` | 透明前缀，用于“从某处获取”的自然语序，不改变语义 |

它是上下文相关的软关键字：独立成词且后面紧跟表达式时被忽略，其他情况下仍可作为普通标识符（如函数名 `从年月日`）。

## 注释

`#` 是注释符号（仅半角，全角 `＃` 不支持），到行尾结束。中文写法 `注释` 后接空白、冒号或行尾时同样作为注释起始；写成 `注释这是` 这类粘连形式时仍是普通标识符。

另见 [内建函数](../sdk/builtins)。
