# 模型与错误

## 模型与外部方法

```凡
定义 模型 矩形
    变量 整数 宽
    变量 整数 高
结束

定义 矩形 的 方法 初始化(宽 整数，高 整数)
    自己.宽 = 宽
    自己.高 = 高
结束

定义 矩形 的 方法 面积() -> 整数
    返回 自己.宽 乘 自己.高
结束

变量 r = 矩形(3, 4)
打印(r 的 面积())      # 12
```

## 嵌入

```凡
定义 模型 人
    变量 字符串 姓名
结束

定义 人 的 方法 介绍()
    返回 "我是 " 加 自己.姓名
结束

定义 模型 学生
    嵌入 人
    变量 整数 学号
结束

变量 s = 学生()
s.姓名 = "小明"
s.学号 = 1
打印(s.介绍())         # 我是 小明
```

## 值、错误

```凡
函数 除法(a 整数、b 整数) -> (整数，错误)
    如果 b 等于 0 那么
        返回 0、错误("除数不能为零")
    结束
    返回 a / b、空
结束

变量 结果、e = 除法(10, 2)
如果 e 等于 空 那么
    打印("结果：", 结果)    # 结果： 5
结束
```

## 检查传播

```凡
函数 安全除法(a 整数、b 整数) -> (整数，错误)
    变量 值 = 检查 除法(a, b)
    返回 值、空
结束

变量 x、e2 = 安全除法(8, 0)
打印("错误：", e2.消息)       # 错误： 除数不能为零
```

## 抛出和捕获

```凡
函数 必须成功(值 整数)
    稍后 函数()
        变量 异常 = 捕获()
        打印("恢复：", 异常)
    结束
    如果 值 小于等于 0 那么
        抛出 "值必须大于零"
    结束
结束

必须成功(0)
```

## 一个小综合：安全计算面积

```凡
定义 矩形 的 方法 安全面积() -> (整数，错误)
    如果 自己.宽 小于等于 0 或 自己.高 小于等于 0 那么
        返回 0、错误("宽高必须为正数")
    结束
    返回 自己.宽 乘 自己.高、空
结束

变量 r = 矩形(0, 4)
变量 面积、e3 = r.安全面积()
如果 e3 不等于 空 那么
    打印(e3.消息)             # 宽高必须为正数
结束
```
