# 模块

模块示例的源码位于解释器仓库的 `examples/modules/` 目录。

## 被导入的模块

`modules/统计/统计.凡`：

```凡
公开 函数 总和(arr 数组) -> 整数
    变量 合计 = 0
    遍历 arr 中的 项
        合计 = 合计 加 项
    结束
    返回 合计
结束

公开 函数 平均值(arr 数组) -> 小数
    变量 合计 = 0.0
    遍历 arr 中的 项
        合计 = 合计 加 项
    结束
    返回 合计 / 长度(arr)
结束
```

`modules/问候/问候.凡`：

```凡
公开 变量 语言 = "中文"

公开 函数 打招呼(名字 字符串) -> 字符串
    返回 "你好，" 加 名字
结束
```

## 主程序

```凡
导入 "modules/问候/问候" 作为 hi
导入 "modules/统计/统计"

打印(hi.语言)
打印(hi.打招呼("小明"))

变量 名单 = [10, 20, 30, 40]
打印("总和：", 统计.总和(名单))
打印("平均值：", 统计.平均值(名单))
```

输出：

```text
中文
你好，小明
总和： 100
平均值： 25
```

## 非公开成员不可见

模块内未加 `公开` 的函数、变量，只能在模块文件内部使用，导入方访问会报错：

```凡
# 模块文件中
函数 内部辅助()
    返回 "私有"
结束
```

```凡
# 导入方
导入 "modules/某模块"
某模块.内部辅助()      # 错误：模块没有公开成员 内部辅助
```

这就是凡语言目前的核心功能。需要快速回顾全部语法，见 [语法速查](../reference/cheatsheet)。
