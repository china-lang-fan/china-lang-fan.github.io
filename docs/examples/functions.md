# 函数与多返回值

## 基本函数

```凡
函数 求和(整数 a, 整数 b)
    返回 a 加 b
结束

打印(求和(3, 4))         # 7
```

## 带类型的函数

```凡
函数 平方(整数 n) -> 整数
    返回 n 乘 n
结束

打印(平方(6))           # 36
```

## 递归：斐波那契

```凡
函数 斐波那契(整数 n) -> 整数
    如果 n 小于 2 那么
        返回 n
    结束
    返回 斐波那契(n 减 1) 加 斐波那契(n 减 2)
结束

打印(斐波那契(10))      # 55
```

## 闭包计数器

```凡
函数 造计数器()
    变量 n = 0
    函数 计数()
        n = n 加 1
        返回 n
    结束
    返回 计数
结束

变量 c = 造计数器()
打印(c())              # 1
打印(c())              # 2
打印(c())              # 3
```

## 多返回值：商和余数

```凡
函数 商余(整数 a、整数 b) -> (整数，整数)
    返回 a / b、a % b
结束

变量 商、余数 = 商余(17, 5)
打印("商：", 商, "余数：", 余数)   # 商： 3 余数： 2
```

## 多返回值自动展开

```凡
函数 相加(整数 a、整数 b)
    返回 a 加 b
结束

打印(相加(商余(17, 5)))   # 5（相当于 相加(3, 2)）
```

## 函数作为参数

```凡
函数 应用两次(任意 函数值，整数 x)
    返回 函数值(函数值(x))
结束

函数 加一(整数 n)
    返回 n 加 1
结束

打印(应用两次(加一, 10))   # 12
```
