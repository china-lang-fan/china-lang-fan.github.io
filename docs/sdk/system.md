# 系统

基础 SDK 的 `库/系统.凡` 包装解释器内置的基础能力。其中 `打印`、`长度`、`追加`、
`错误`、`捕获` 等同时也是无需导入的[内建函数](./builtins)；本模块把它们与
`类型名`、`截断`、`编码点`、`字符`、`失败` 一起以 `本地` 绑定形式暴露，便于统一导入。

```凡
导入 "库/系统" 作为 系统

打印(系统.类型名(1))      # integer
打印(系统.截断(3.9))      # 3
```

## 函数

| 函数 | 说明 |
| --- | --- |
| `打印(值…)` | 输出值到标准输出（不额外换行，多参数原样拼接） |
| `构造错误(消息)` | 创建一个错误值，等价于内建 `错误(...)` |
| `类型名(值)` | 返回运行时类型的英文标识，如 `integer`、`string`、`array` |
| `截断(数字)` | 将数字向零截断为整数 |
| `编码点(单字符串)` | 返回单个字符的 Unicode 编码（`ord`） |
| `字符(整数)` | 按 Unicode 编码构造单字符串（`char`） |
| `长度(值)` | 数组/字符串/字典的长度（`len`） |
| `追加(数组, 值…)` | 返回末尾追加元素后的新数组，不改原数组（`append`） |
| `失败(消息 = "断言失败")` | 抛出一个失败错误，供测试框架使用（`fail`） |

## 与内建的关系

`打印`、`长度`、`追加`、`构造错误` 在解释器内有同名中文内建（`打印`/`长度`/
`追加`/`错误`），不导入本模块也能直接调用；导入模块则拿到命名空间限定的同一实现。
完整的错误值成员（`消息`、`错误码`、`详情`、`原因`、`调用栈`、`追踪`）见
[错误处理](../guide/errors)。
