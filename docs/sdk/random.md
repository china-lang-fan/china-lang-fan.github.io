# 随机

基础 SDK 的 `随机.凡` 提供随机数和随机选择功能。

```凡
导入 "随机" 作为 随机模块

打印(随机模块.随机整数(10))
打印(随机模块.选择(["甲", "乙", "丙"]))
```

## 随机数

| 函数 | 说明 |
| --- | --- |
| `随机整数(最大值)` | `[0, 最大值)` 范围内的整数 |
| `整数范围(最小值, 最大值)` | `[最小值, 最大值)` 范围内的整数 |
| `随机小数()` | `[0, 1)` 范围内的小数 |
| `小数范围(最小值, 最大值)` | 指定范围内的小数 |
| `随机布尔()` | 随机布尔 |
| `概率(概率值)` | 以指定概率返回真 |

## 随机选择

| 函数 | 说明 |
| --- | --- |
| `选择(数组)` | 随机选择一个元素 |
| `打乱(数组)` | 返回打乱顺序后的新数组 |
| `抽样(数组, 数量)` | 随机选取指定数量的元素，不重复 |
| `任一(数组)` | 随机选择一个元素 |

所有选择函数都不会修改原数组。
