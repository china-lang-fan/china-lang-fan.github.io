# 模块工具

`库/模块工具.凡` 是一个**示例模块**，用于演示凡语言的模块导入与[分段函数](../guide/functions#分段函数)
写法，本身只含两个简单函数，不依赖任何原生实现。

```凡
导入 "库/模块工具" 作为 工具模块

打印(工具模块.加倍(21))                 # 42
打印(工具模块.求([3, 9, 2])的最大值())    # 9
```

## 函数

| 函数 | 说明 |
| --- | --- |
| `加倍(整数 数)` | 返回 `数 乘 2` |
| `求(数组 数列)的最大值()` | 分段函数形式，遍历返回数列中的最大值 |

其中 `求(...)的最大值()` 展示了 mixfix 分段函数：函数名由多段标识符构成，
调用时实参填在各段之间。新增模块时可参照本文件的目录组织与 `公开` 导出方式。
