# 字符串

基础 SDK 的 `库/字符串.凡` 提供字符串处理函数，并为原生 `字符串` 类型注册同名方法。
两种调用形式等价：

```凡
导入 "库/字符串" 作为 字符串模块

打印(字符串模块.包含("你好凡", "凡"))     # 真
打印("你好凡".包含("凡"))                 # 真（成员形式）
```

## 函数与方法

| 模块函数 | 同名方法 | 说明 |
| --- | --- | --- |
| `截取(文本, 开始, 末位置 = -1)` | `文本.截取(开始, 末位置)` | 切片，`末位置` 为 -1 时取到末尾 |
| `位置(文本, 子串)` | `文本.位置(子串)` | 子串首次出现的下标，找不到返回 -1 |
| `包含(文本, 子串)` | `文本.包含(子串)` | 是否包含子串 |
| `开头是(文本, 前缀)` | `文本.开头是(前缀)` | 是否以前缀开头 |
| `结尾是(文本, 后缀)` | `文本.结尾是(后缀)` | 是否以后缀结尾 |
| `拆分(文本, 分隔符)` | `文本.拆分(分隔符)` | 按分隔符拆成数组 |
| `连接(数组, 分隔符)` | — | 用分隔符把字符串数组连成一个字符串 |
| `替换(文本, 旧串, 新串)` | `文本.替换(旧串, 新串)` | 替换子串 |
| `修剪(文本)` | `文本.修剪()` | 去除首尾空白 |
| `转小写(文本)` | `文本.转小写()` | 转为小写 |
| `转大写(文本)` | `文本.转大写()` | 转为大写 |

此外 `取字符(文本, 位置)`（模块内私有）按位置取单个字符，供上述函数复用。

字符串的索引、切片、插值与遍历等语法能力见 [字符串指南](../guide/strings)。
