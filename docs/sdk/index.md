# 标准库

凡语言的标准库由内建函数和随解释器分发的 SDK 模块（`sdk/*.凡`）组成。模块通过 `导入` 引入，内建函数无需导入即可直接使用。

## 内建

- [内建函数](./builtins)：`打印`、`长度`、`追加`、`错误` 等无需导入的函数。

## 基础

- [数学](./math)：`数学.凡`，常用数学函数与常量。
- [随机](./random)：`随机.凡`，随机数、抽样与打乱。
- 系统：`系统.凡`，类型名、环境变量、命令行参数等（文档待补）。

## 文本与集合

- [正则](./regex)：`正则.凡`，正则匹配、查找与替换。
- [类型转换](./conversion)：`转换.凡`，整数、小数、字符串、字节、字符等互转。
- 字符串：`字符串.凡`，字符串方法（见[原生类型方法](../guide/primitive-methods)，独立参考页待补）。
- [数组](../guide/arrays) 与 [字典](../guide/dicts)：语法与内置方法。
- 模块工具：`模块工具.凡`，分段函数工具如 `求(数列)的最大值()`（文档待补）。

## 时间

- [时间](./time)：`时间.凡`，时刻、耗时与睡眠。
- [日期](./date)：`日期.凡`，日期、月份与格式化。

## 系统交互

- [文件](./files)：`文件.凡`，文件与目录读写。
- [进程](./process)：`进程.凡`，执行外部命令。
- [网络](./network)：`网络.凡`，HTTP 请求。
- [编码](./encoding)：`编码.凡`，Base64、十六进制、URL 与 JSON 编解码。

## 测试

- [测试](./testing)：`测试.凡`，轻量测试框架与断言。

## 使用方式

```凡
导入 "数学" 作为 数学模块

打印(数学模块.平方根(16))    # 4
```

模块名即文件名（不含 `.凡`）；跨模块只能访问以 `公开` 声明的函数、模型与变量，详见[模块](../guide/modules)。
