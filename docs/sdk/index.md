# 标准库

凡语言的标准库由内建函数和随解释器分发的 SDK 模块组成，源码位于 `fan-sdk` 仓库，按用途分两个目录存放：`库/` 放 16 个库模块（`库/*.凡`），`测试/` 放对应的 `*_测试.凡`。模块通过 `导入` 引入，内建函数无需导入即可直接使用。

## 内建

- [内建函数](./builtins)：`打印`、`长度`、`追加`、`错误` 等无需导入的函数。

## 基础

- [数学](./math)：`库/数学.凡`，常用数学函数与常量。
- [随机](./random)：`库/随机.凡`，随机数、抽样与打乱。
- [系统](./system)：`库/系统.凡`，类型名、截断、编码点、失败断言等基础内建。

## 文本与集合

- [正则](./regex)：`库/正则.凡`，正则匹配、查找与替换。
- [类型转换](./conversion)：`库/转换.凡`，整数、小数、字符串、字节、字符等互转。
- [字符串](./strings)：`库/字符串.凡`，截取、查找、拆分、替换、修剪与大小写。
- [数组](../guide/arrays) 与 [字典](../guide/dicts)：语法与内置方法。
- [模块工具](./module-tools)：`库/模块工具.凡`，演示模块导入与分段函数的示例模块。
- 标签工具：`库/标签工具.凡`，`注册标签处理` 的统一入口，说明见[标签](../guide/tags)。

## 时间

- [时间](./time)：`库/时间.凡`，时刻、耗时与睡眠。
- [日期](./date)：`库/日期.凡`，日期、月份与格式化。

## 系统交互

- [文件](./files)：`库/文件.凡`，文件与目录读写。
- [进程](./process)：`库/进程.凡`，执行外部命令。
- [网络](./network)：`库/网络.凡`，HTTP 请求。
- [编码](./encoding)：`库/编码.凡`，Base64、十六进制、URL 与 JSON 编解码。

## 测试

- [测试](./testing)：`库/测试.凡`，轻量测试框架与断言。

## 使用方式

```凡
导入 "库/数学" 作为 数学模块

打印(数学模块.平方根(16))    # 4
```

导入路径统一以 `库/` 前缀书写、相对 SDK 根解析；库模块之间也用同样的根相对路径互导。模块名即文件名（不含 `.凡`）；跨模块只能访问以 `公开` 声明的函数、模型与变量，详见[模块](../guide/modules)。标准库中由原生代码实现的部分通过 `本地` 绑定接入，见[本地绑定](../guide/functions#本地绑定)。
