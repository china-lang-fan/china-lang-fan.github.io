# 内建函数

凡语言目前提供以下内建函数，可以直接调用，无需导入。

## 打印

输出一个或多个值到标准输出，**不追加换行**。规则：

- **多个实参**：原样逐个拼接，不插任何分隔符。
- **单个数组实参**：展开数组元素，元素之间以一个空格连接。

需要换行时用 `打印行`，或自行在实参中写入换行符。

```凡
打印("你好")
打印("a：", 1, "b：", 真)
打印([1, 2, 3])
打印("A")
打印("B")
```

```text
你好a：1b：真1 2 3AB
```

上例中前四行 `打印` 都不换行，输出连成一片；单个数组被展开为空格分隔。

## 打印行

与 `打印` 参数规则完全相同，区别只是在输出末尾**追加一个换行符**，适合逐行输出：

```凡
打印行("第一行")
打印行("第二行")
打印行()
```

```text
第一行
第二行

```

`打印行()` 不带参数时只输出一个空行。需要在同一行内多次拼接、最后统一换行时，
连续用 `打印` 累积内容、再调用一次无参 `打印行()` 收尾即可。


## 长度

返回集合的长度，支持数组、字符串和字典。

| 参数 | 返回 |
| --- | --- |
| 数组 | 元素个数 |
| 字符串 | 字符（rune）个数 |
| 字典 | 键值对个数 |

```凡
打印(长度([1, 2, 3]))     # 3
打印(长度("你好"))         # 2
打印(长度({"a": 1}))      # 1
```

## 追加

`追加(数组, 值…)`：返回在数组末尾加入一个或多个新元素后的**新数组**，不修改原数组。

```凡
变量 a = [1, 2]

打印(追加(a, 3))         # [1, 2, 3]
打印(追加(a, 3, 4, 5))   # [1, 2, 3, 4, 5]
打印(a)                 # [1, 2]
```

第一个参数必须是数组。

## 错误

`错误("消息")` / `error("消息")`：创建一个错误值。消息参数会被转为文本。

```凡
变量 e = 错误("出错了")
变量 e2 = error("英文名称也可用")
打印(e)                 # 错误：出错了
打印(e.消息)            # 出错了
```

错误处理的完整用法见 [错误处理](../guide/errors)。

## 崩溃了

`崩溃了(错误描述)`：触发运行时崩溃（类似 Go `panic`），接受一个字符串描述，
内部构造带调用栈的规范错误对象并展开调用栈。只能被上层 `稍后` 中的 `恢复()` 接管。

```凡
崩溃了("配置缺失：" + 配置路径)
```

## 恢复

`恢复()`：在 `稍后` 注册的函数中取回当前崩溃的错误对象；没有正在展开的崩溃时返回 `空`。

```凡
函数 f()
    稍后 函数()
        变量 异常 = 恢复()
        如果 异常 不等于 空 那么
            打印行(异常.消息)
        结束
    结束
    崩溃了("失败")
结束
```

## 运行时类型

`type(值)`：返回运行时类型的英文名称。

```凡
print(type(1))         # integer
print(type("x"))       # string
print(type([]))        # array
```

类型名称包括：`integer`、`float`、`string`、`boolean`、`nil`、`array`、`dict`、`error`、`tuple`、`module`、`function`、`class`、`instance`。

## 数值截断

`trunc(数字)`：将数字向零截断为整数。

```凡
print(trunc(1.9))      # 1
print(trunc(-1.9))     # -1
```

## Unicode 字符编码

`ord(单字符串)`：返回单个字符的 Unicode 编码。

```凡
print(ord("A"))        # 65
print(ord("凡"))       # 20961
```

`char(整数)`：根据 Unicode 编码构造单字符串。

```凡
print(char(65))        # A
print(char(20961))     # 凡
```

## 注册标签处理

`注册标签处理(标签名, 处理函数)`：把凡语言函数注册为标签处理器。

```凡
注册标签处理("自定义", 处理函数)
```

标签系统的完整说明见 [标签](../guide/tags)。

## 成员形式速查

部分功能也可通过成员访问获得：

| 接收者 | 成员 | 说明 |
| --- | --- | --- |
| 数组 | `长度` | 元素个数 |
| 数组 | `反转` | 反转后的新数组 |
| 字典 | `长度` | 键值对个数 |
| 字典 | `键` | 键组成的数组 |
| 字典 | `值` | 值组成的数组 |
| 错误 | `消息` | 消息字符串 |

```凡
[1, 2, 3] 的 长度
{"a": 1} 的 键
错误("x").消息
```

## 系统基础模块

`库/系统.凡` 用 `本地` 绑定把解释器的原生实现包装成可导入的凡语言函数。`本地` 的完整说明见[本地绑定](../guide/functions#本地绑定)。

```凡
导入 "库/系统" 作为 系统

系统.打印(系统.类型名(1))
```

该模块有 9 个本地绑定函数，其中 8 个以 `公开` 暴露：`构造错误`、`类型名`、`截断`、`编码点`、`字符`、`长度`、`追加` 和 `失败`；`打印` 仅模块内使用，保持私有。

`库/测试.凡` 基于 `失败` 提供测试断言，详见 [测试指南](./testing)。
